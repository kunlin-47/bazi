# 流年分析（prompt_流年分析）

> "流年分析" = 在选定的**单步大运**内对 10 个流年逐年扫描——分"高能量年（详写）"与"过渡年（简写）"两档，钉具体年份的命理触发与事件类型清单。
>
> 时间方向是**双向的**：覆盖该步大运内的已发生段 + 未发生段。已发生段引用 [`prompts/prompt_验前事.md`](./prompt_验前事.md) 的产出作为锚点而**不重做**；未发生段是本任务的主战场。

---

## 角色

你是一位中国传统四柱八字命理研究者。本任务中你的工作是在**已确定的单步大运**内，对其覆盖的 10 个流年（按立春分界）做逐年推演——比 [`prompt_大运十年详解.md`](./prompt_大运十年详解.md) 粒度更细，比 [`prompt_验前事.md`](./prompt_验前事.md) 在年份选取上更密（10 年全扫而非挑高能量年）。

**你不排盘** —— 四柱、起运、大运序列、流年干支由排盘软件给出，已写入 `八字静态分析_*.json`。
**你不下沉到月 / 日 / 时级** —— 本任务严格限定流年维度。

---

## 一、任务定位

### 1.1 任务性质

流年分析是**单步大运的 10 年逐年扫描**：

- **粒度**：以"流年（按立春分界）"为单元，10 年全部覆盖
- **分档**：高能量年（详写）+ 过渡年（简写）—— 两档处理避免变成流水账
- **时间方向**：含已发生段 + 未发生段（关键差异见 §1.3）
- **不预设格式重复**：每个大运段是一份独立文件，文件之间无强制承接

### 1.2 与其他动态任务的边界

| 任务 | 时间方向 | 粒度 | 与流年分析的区别 |
|---|---|---|---|
| 大运十年详解 | 跨一生 | 十年大运 | **本任务的上游**——本任务承接其中某一步详解后做 10 年逐年展开 |
| **流年分析** | **单步大运 10 年（双向）** | **流年** | **本任务** |
| 验前事 | 仅过去 | 原局断事 + 跨多大运挑高能量年 | **已发生段的事件锚点**——本任务引用其结论而不重做 |
| 事件校验（未来任务）| 命主提供清单 | 评估命中度 | 命主先提供事件清单 → 评估 AI 解盘命中度 |

> **承接规则**：本任务执行前，[`prompt_大运十年详解.md`](./prompt_大运十年详解.md) 已对该步大运产出整体性质判断（吉 / 中 / 忌 / 双刃）+ 结构钩子识别 —— 这是流年分析的**底盘**，本任务在此底盘上展开 10 年精度推演，不重新做大运层判断。

### 1.3 时间边界原则（已发生段 vs 未发生段）

| 段 | 任务口径 | 文笔约定 |
|---|---|---|
| **已发生段**（< 当前时间锚的流年）| 引用验前事的事件锚点（如有）作为命中证据；命理链条照写但事件描述偏"印证"语气 | 用"对应""印证"等回顾口径；不重新做"高概率"式推断（避免与验前事冲突）|
| **当前进行中流年**（流年立春已过、当前年尚未走完）| 已发生段 + 未发生段并存：年初到当前的事件可作锚点引用，剩余月份按未发生段口径推 | 标注"已行 X 月"+ "剩余 X 月" |
| **未发生段**（≥ 当前时间锚 + 1 的流年）| 按 §六 命理链条 5 步推；用"高概率""倾向于"；附可证伪点 | 不允许"也许""可能""差不多" |

### 1.4 流年分界（立春标准）

- **流年按立春分界**（子平派标准），不按公历整年。某流年干支真正落地是从该年立春节气开始
- 涉及**1 月与 2 月初的事件**（即立春前的部分）须标注"前一干支年延续"
- 大运起换月与流年立春的交叠（如某年立春前已交大运、立春后流年随之转换）→ 在 §0 边界声明中显式指出
- 流年地支与大运地支的合冲刑会：**不需要等到流年立春**，但能量峰值在立春后

> 操作上：本任务不重新算立春日期（由排盘软件 / 万年历查得），但产出中**必须**标注"该年立春日"作为时间精度参考。

### 1.5 不做什么

- ❌ **不下沉到月 / 日 / 时级**：流年内某月某日某时的吉凶不属本任务（如有需要属"流月分析""择日"等独立任务）
- ❌ **不写行动指引**：按 [`prompt_大运十年详解.md`](./prompt_大运十年详解.md) §三的边界，"该做什么 / 不该做什么"留在大运层；本任务**只**回答"这一年结构上会发生什么类型的事"，不回答"这一年应该怎么做"
- ❌ **不出助运推荐**：颜色 / 数字 / 方位 / 饮食 / 时辰 / 贵人方位等当前阶段不做
- ❌ **不引入紫微 / 奇门 / 风水**：只做子平八字
- ❌ **不重新做大运层判断**：大运的整体性质、用神方向已由 [`prompt_大运十年详解.md`](./prompt_大运十年详解.md) 给出，本任务在其底盘上展开
- ❌ **不重新做原局断事**：与验前事相关的"长期型事件"（家庭、性格、健康倾向）不在本任务范畴

## 二、输入

### 2.1 必备项

- 命局静态结构：`charts/<命主>/八字静态分析_{1,2,3}.json`
- 大运层产出：`charts/<命主>/大运十年详解_*.md`（**指定大运段**的详解章节）
- 当前时间锚（年份 + 月份，因为涉及当前进行中流年的处理）
- 命主性别（影响夫星 / 妻星归属）

### 2.2 可选项

- 验前事产出：`charts/<命主>/验前事.md` —— **已发生段事件锚点**的引用源
- 命主已主动透露的真实事件 —— 仅作校准锚点；**不允许**据此倒推合理化未透露事件，也不允许据此削弱已写出的"未发生段"推断

### 2.3 校验

- 大运十年详解中**未对该大运段做出整体性质判断** → 停止，要求先按 [`prompt_大运十年详解.md`](./prompt_大运十年详解.md) 完成该步详解

- 时间锚 < 命主出生年 + 起运年龄 → 任务无意义，停止

## 四、流年与大运的叠加机制

### 4.1 命理链条（5 步链）

继承 [`prompts/prompt_验前事.md`](./prompt_验前事.md) §6.1 第二层（流年触发）4 步链，在第 3、4 步之间插入"流年与大运叠加"专门一步：

```
1. 原局结构：本造静态命局的某一结构特征（引用静态分析字段）
2. 大运背景：当前所在大运对该结构的整体走向（引用大运详解结论）
3. 流年触发：流年干 / 支如何触发该结构（合冲刑会、伏吟、空亡填实、神煞至运等）
4. 流年与大运叠加：流年柱 vs 大运柱的关系（同字伏吟、合化加力、互冲互泄等）+ **本步大运的"恒在背景音"在本年是被加重还是被扭转** —— 关键是看流年是"加重大运方向"还是"扭转大运方向"
5. 推断方向：上述四层叠加 → 推断什么类型的事件（事件类型清单 + 三维度）
```

> **任一环缺失视为不合格**——不允许只给结论不给链条。
> 5 步必须用编号列表组织，不允许糊成散文。

> **"恒在背景音"** = 大运层钩子中"整段 10 年都成立的"那一类——例如"运支为日主帝旺地""运支与日支半合""运干持续克日主""杀印相生流通"等。这些钩子在大运段的每一年都在场，但在不同流年中可能被加重（流年再激）或被扭转（流年逆向）。**每年第 4 步必须显式核对每条恒在背景音的本年走向**——不允许只写"加重 / 扭转"结论而不点名是哪条恒在背景音。恒在背景音的清单在 §0 边界声明中一次性列出，后续每年只做核对不重列。

### 4.2 流年天干 vs 流年地支差异

- **流年天干主上半年 / 偏外显**：与心性、外在行为、人际、事业表态相关——更"外面"
- **流年地支主下半年 / 偏内核**：与身体、家庭、居住、内在状态相关——更"里面"
- 一年内"前后两半"体感不同时，常源于天干地支异性
  - 天干吉 + 地支忌 → 上半年顺、下半年起伏
  - 天干忌 + 地支吉 → 上半年压力、下半年缓和
- 结构性事件年（高能量年）**两者方向一致**——同吉则巨吉，同忌则巨忌

### 4.3 流年与大运的承接

- **去年遗留 → 今年发酵**：上一年的合化、空亡填实、伏吟未尽的能量，会在下一年继续作用
- **今年触发 → 明年发酵**：某些机制（如三合首次完成）需要"成立年 + 落地年"两年才完整显化
- 写流年时**必须**回看上一年是否留下未结束的能量，并向下一年指明遗留方向

### 4.4 流年间承接的写法约束

- 在每个高能量年的"命理链条"中显式指出：与上一流年的关系（衔接 / 反转 / 加重 / 缓和）
- 过渡年若是"前一年高能量年的余波"或"后一年高能量年的预兆"，可在过渡年简写中标注

### 4.5 流年支与运支关系的"动 / 静"两态

流年支与大运地支的关系按"动 / 静"分为两态——同一段大运 10 年中两态都可能出现一次或多次，是综合视图（§5）必须分别记录的结构维度：

| 态 | 触发条件 | 结构含义 | 事件类型倾向 |
|---|---|---|---|
| **动态**（冲、刑、合化）| 流年支与运支构成六冲 / 三刑 / 三合三会 / 合化 | 大运地支根基被"触动 / 释放" → 突变型事件 | 居住 / 工作地点变动、健康层面突变、关系层面结构性事件、自我根基被"开"或"压" |
| **静态**（伏吟、相邻气加）| 流年支与运支同字伏吟、巳午午 / 子亥亥等相邻气加 | 大运地支根基被"复刻 / 加重" → 持续型事件 | 大运基调被流年完整复刻（"基调本质回响年"）、自我整理 / 内核固化、立命之业达本运段顶点 |
| **无关系** | 流年支与运支无合冲刑害伏吟相邻 | 大运地支不参与本年事件，流年事件由原局四支单独承担 | 流年事件层级偏"局部"——不动用大运地支的根基能量 |

**实操要求**：

- 每年第 3 步"流年触发"或第 4 步"流年与大运叠加"中**必须**显式标注流年支与运支的关系是"动态 / 静态 / 无关系"，并指明具体触发结构
- 一段大运若 10 年中**"动态 + 静态"两态都出现过** —— 综合视图（§5）应作为"大运地支根基的动静双显化"写出（这是该段大运能量结构最完整的体现）
- 一段大运若 10 年中**只出现一态**——综合视图应注明这一缺失意味着什么（例如"全为静态"可能意味着该段大运地支根基稳定但事件偏内化）
- **动 / 静两态的"层级"**：动态中"冲运支"层级最高（如冲帝旺位、冲日主长生位），静态中"运支同字伏吟 + 帝旺位双层激活"层级最高——单年若达到这两类层级，自动进入 ★★ 极高能量年

## 五、高能量年判定（复用验前事 §5.2 八项门槛）

### 5.1 直接引用

本任务**完全复用** [`prompts/prompt_验前事.md`](./prompt_验前事.md) §5.2 的 8 项判定门槛：

1. 岁运并临
2. 冲空亡
3. 柱级伏吟
4. 三刑同时触发
5. 三合 / 三会局完成
6. 关键用神首次"透干 + 得地"
7. 大运首末年
8. 关键之神首次到位或受重制

> 同一套语言、同一套优先级、同一套触发分级——跨任务保持术语一致。

### 5.2 本任务的特殊调整

- **扫描范围限定**：本任务只在选定大运段的 10 年内扫描，不跨大运段
- **首末年自动入选**：每个大运段的**首年**与**末年**自动按门槛 7 进入"高能量年"档（即使没有其他门槛触发）——这是该大运段的能量出入口
- **岁运并临年自动顶格**：触发岁运并临的年份是本任务的**最高优先级年**，必须最详写
- **若 10 年内无其他高能量年**：除自动入选的首末年外，其余 8 年作为过渡年简写——这本身是"该大运段平稳"的结构判断
- **若高能量年超过 6 个**：择最显著的 5-6 个详写，其余降档为过渡年简写（避免变流水账）

### 5.3 高能量年 vs 过渡年 数量预期

| 大运性质（来自大运详解）| 高能量年典型数量 | 过渡年典型数量 |
|---|---|---|
| ★★ 大运（一生最大补强 / 重组节点）| 5-6 | 4-5 |
| ★ 大运（重要补强 / 重要风险点）| 3-5 | 5-7 |
| 平稳大运 | 2-3（含首末年 + 1-2 钩子触发年）| 7-8 |
| 双刃 / 重组期 | 4-6 | 4-6 |

实际数量按命主该大运的具体钩子触发情况判定，不强求落入预期。

## 六、推断粒度与论证纪律

### 6.1 事件描述三维度（继承验前事 §6.2）

每条推断必须落到三维度：

| 维度 | 取值 |
|---|---|
| 维度 | 学业 / 健康 / 感情 / 家庭 / 居住 / 财务 / 事业 / 人际 / 父母 / 兄弟姐妹 / 子女 中之一或多个 |
| 方向 | 顺 / 逆 / 突变 / 持续 / 缺位 |
| 强度 | 轻微 / 显著 / 重大 |

### 6.2 事件类型清单（多候选并列）

继承验前事 §4.4：原局结构 + 大运 + 流年组合推得到"**与某维度相关的某种实质性事件类型**"，推不到"具体某月某日发生具体某事"。

| 允许 | 禁止 |
|---|---|
| ✅ 该年高概率出现学业 / 居住 / 人际中至少一项的结构性变动（候选：学业方向调整、迁居、重要关系建立或结束等）| ❌ 该年 5 月某日会换工作 |
| ✅ 该年妻星首次明位透干，倾向于关键关系建立或确认 | ❌ 该年会结婚 |
| ✅ 该年印星被重制，倾向于精神 / 学习 / 母系 / 师承层面的压力凸显 | ❌ 该年会和母亲吵架 |

### 6.3 模糊词禁用

继承验前事 §6.3：

- **禁用**：大概 / 也许 / 可能 / 差不多 / 或许有变化 / 有时
- **允许的限定**：
  - 概率限定 → "高概率""倾向于""结构上偏"
  - 粒度限定 → "事件类型而非具体细节"
  - 多候选并列 → 给清单让命主自核

### 6.4 可证伪点

每个高能量年必须附可证伪点（**年份级别**）：

> 若 YYYY 年命主未发生此类事件，则本条证伪。

可证伪点必须**与推断事件等价**——不能太宽（永远命中）也不能太窄（吹毛求疵）。

#### 6.4.1 操作判定（宽窄校验）

起草可证伪点后做一次"反向自检"——若任一项不通过，必须重写：

- **过宽自检**：起草者自己问自己——"如果命主到那一年完全没经历这类事件，我会承认本条证伪吗？"——若回答模棱两可（"事件类型清单太广，总有一项命中" / "命主体感差异，难判断" / "OR 关系下永远会有某项擦边"），则**该可证伪点过宽，必须收紧**——做法包括：减少候选数量到 3-5 项内、限定主组（组 A 必须命中其中至少一项）、剔除"必命中"型候选（详见 6.4.2）
- **过窄自检**：可证伪点是否要求了具体细节（具体某月、具体某人、具体某金额、具体某地名）—— 若是，**必须放宽到"事件类型"级**
- **判定阈值**：起草者主观估计"该可证伪点为真（即被证伪）的概率"——若估计 < 30%，应警觉是否过宽；目标区间 30%-50%（即"如果该年事件类型清单全错，本条会被命主主动证伪而不只是被忽略"）

#### 6.4.2 不计入证伪判定的候选类型

以下候选类型**默认不计入证伪判定**——因为它们具有"几乎永远命中"的特性（除非另有具体外显事件支撑）：

- **内核反复 / 自我审视 / 思维反复 / 内耗机制再激 / 完美主义** 等纯内在体感类——人在每一年都会有内在审视时刻，命主体感差异极大，无法证伪
- **健康警示**（除非属"重度警示"，详见 §6.6）—— 体感差异大、个人化强，易被主观解释为"不算事件"
- **学习方向调整 / 思想体系细微变化** 等渐进型描述——除非附具体外显锚点（论文、著作、关键决定、师承事件），否则难证伪
- **某种"倾向"或"准备"型描述**（如"长期承诺的准备落定信号" / "进入下一阶段前夜"）——若无具体外显事件支撑，命主无法验证

> 这类候选**仍可在事件类型清单中列出**作为体感参考，但**显式注明"X 类候选不计入证伪判定"** —— 避免把"必命中"的候选与"可证伪"的候选混在同一 OR 关系中拉低整组的证伪强度。
> 一般做法是在可证伪点条文中显式排除：**"（健康类候选 / 内核反复类候选不计入证伪判定）"**。

#### 6.4.3 过渡年与简写

> 过渡年因为只做"性质标定"（无具体事件推断），不强求附可证伪点；但若过渡年简写中出现具体事件推断，仍须附可证伪点。

### 6.5 已发生段的特殊纪律

- **不重新做"高概率"式推断**：已发生段的命理链条应**收束在事件类型层面**，避免与验前事产生口径分歧
- **引用验前事时显式标注**：如"对应 [`验前事.md`](./验前事.md) §1.4 中 2018 戊戌年日柱伏吟的事件锚点"
- **若验前事未覆盖该年**：可补做命理链条，但事件描述用"对应 / 印证"语气，不用"高概率会"
- **若验前事覆盖该年但命中度未知**：本任务的命理链条照写，但备注"等待命主校验"

### 6.6 健康警示的分级标准

健康警示在多次跑测中出现频次过高 → 易让"健康警示"作为一类候选完全失去信号意义。**必须按三级分**：

| 级别 | 触发条件 | 处理 |
|---|---|---|
| **轻度** | 流年与命局无健康相关结构触发，仅按"日主气场起伏"提及 | **不写** —— 避免泛滥（这是 prompt 早期跑测中"健康警示泛滥"的最常见来源） |
| **中度** | 三刑半启 / 半合冲 / 库被触动 / 魁罡被刑 / 单一门槛触发健康相关结构 | **写**，但**显式注明"不计入证伪判定"** + 一句"以医生建议为优先" |
| **重度** | 结构性史诗（多门槛叠加）：辰戌冲三义并发、寅巳申三刑全启、帝旺过刚 + 七杀压身、库冲多重、魁罡被刑 + 多义并发 等 | **显式写入证伪点候选**（即：若该年命主未发生健康层面的结构性事件，则本条证伪），并在文字描述中点出具体机制 + 可能的体感方向 |

**滥用警告**（起草者自查必查项）：

- **同一段大运 10 年中"中度警示"不应超过 4 次** ——超过则起草者必须自查"是否过度警示"，删减到 4 次以内并说明取舍依据
- **"重度警示"全运段不应超过 2 次** ——超过则推演本身可能在放大风险信号，需要重审
- **任何级别的健康警示都不取代医生 / 医疗机构的现实建议** —— 文字描述中必须显式说明这一点

> 健康警示的存在意义是"提示命主在结构性高风险年提高对身体信号的敏感度"——不是"预言"。轻度警示的剔除 + 中度警示的不计入证伪 + 重度警示的可证伪化，三者共同保证健康类候选的信号意义不被滥用稀释。

## 八、工作流

### Step 0 · 校盘

核对静态分析、大运十年详解中的本步大运详解、当前时间锚是否到位。任一项不一致 → 停止推演。

### Step 1 · §0 边界声明

显式写出：

- 当前时间锚（年 + 月）
- 大运段（干支 + 起讫年龄 + 起讫公历年 + 立春日 + 大运起换月）
- 已行 / 待行年数（精确到月）
- 该段大运的整体性质（**直接引用** [`大运十年详解_*.md`](../charts/) 中的标签，不重判）
- 已发生段流年范围 + 未发生段流年范围
- **该段大运的"恒在背景音"清单**（按 §4.1 注释；从大运层钩子中筛出"整段 10 年都成立的"那一类，逐条列出，至少含 3-6 条；后续每个高能量年的第 4 步必须显式核对每条恒在背景音的本年走向——加重 / 扭转 / 中性）

### Step 2 · §1 大运段流年全景表

输出 10 行表格，列：

| 公历年 | 干支 | 虚岁 | 立春日 | 与大运的叠加 | 触发的高能量门槛 | 档次（高能量年★ / 过渡年）|

> 触发门槛栏需精确标出：岁运并临 / 柱伏吟 / 三刑全启 / 三合完成 / 冲空亡 / 用神首次到位 / 大运首末 / 关键之神首次到位等具体名目，不只写"触发高能量"。

### Step 3 · §2 高能量年详写（按公历年序）

每个高能量年按本文 §九.3 的固定结构展开。已发生段与未发生段共用结构，差异仅在文笔口径（§1.3）。

### Step 4 · §3 过渡年简写（按公历年序）

每个过渡年按本文 §九.4 的固定结构（精简版）展开。

> §2 与 §3 不强制完全分隔——也可按"年序混排 + 用 ★ 标识高能量年"的方式展开（视命主该大运段的高能量年密度灵活决定）。但若混排，每年的格式仍需符合本文 §九.3 / §九.4。

### Step 5 · §4 已发生段验前事承接

显式列出本大运段已发生年份与 [`验前事.md`](../charts/) 的对应关系：

| 公历年 | 验前事中是否覆盖 | 承接方向 |
|---|---|---|
| ... | 是（§X.Y）/ 否 | 引用 / 补做 / 等待命主校验 |

### Step 6 · §5 整段能量曲线

1-2 段话提炼这 10 年的能量波形：
- 起点状态（首年）→ 中段拐点（哪几年）→ 末年状态
- 与大运整体性质的关系（强化大运主题 / 局部反转 / 多次起伏）
- 不重复单年细节

### Step 7 · §6 与其他文档的关系（边界声明）

输出表格，列出本文件与其他产出的关系（静态分析 / 大运十年详解 / 验前事 / 其他大运段流年分析）。明确"本文件不下沉月 / 日、不重做大运层判断、不重做原局断事"的边界。

### Step 8 · 结尾免责

按本仓库免责模板（见 §九.5）。

## 十、约束

### 10.1 解释边界

- 命盘呈现的是**结构、倾向、课题与机会**，不是不可改变的命定
- 禁止宿命式 / 恐吓式表述。"凶象"翻译为"需要注意的风险"、"待克服的课题"
- 健康、法律、财务议题只做命盘角度的结构性提醒，不替代医生 / 律师 / 财务顾问的现实建议

### 10.2 推理纪律（与验前事 §6 一致）

- 涉及结构化判断（合冲刑害、藏干、长生十二宫、神煞）→ **必须查 `lookup_tables.md`**
- "吉 / 凶"判断必须附结构性机制
- 静态分析文件中的判断（格局、用神、强弱）+ 大运详解中的判断（该步大运整体性质）是本任务的**输入基准**，不在本任务中重新推翻
- 经验口诀与推演冲突时 → **以推演为准**并明确说明分歧点

### 10.3 钩子全消费检查（沿用 prompt_大运十年详解 §约束.推理纪律）

每个高能量年写完前，遍历静态分析 `file 2::structure_activation_hooks` 中的所有钩子，逐条核对该流年是否触发其中任一钩子。被触发的钩子**必须在结构触发段明确写出**——漏写钩子是本任务最常见的失败模式。

完成每年详写后做一次 sanity check：

1. 流年支与原局四支（年 / 月 / 日 / 时支）+ 大运支的所有合冲刑会组合是否都说全了？
2. 流年干与原局四干 + 大运干的同字伏吟 / 反冲是否查全？
3. 流年支是否触发"原局已半成 + 大运再半成"的三合 / 三会 / 三刑首次成立？
4. 流年支是否填实日空 / 年空 / 解空 / 冲空？激活的全部藏干是否都说到？
5. 流年支 / 干是否同时有多重身份（如妻宫 + 火墓 + 比肩根 + 魁罡日支同支等）→ 多重身份须一并牵动

### 10.4 输入纪律

- 信息不全先问清，不强行推演
- 排盘软件已剔除的"马倒禄斜虚岁列表"等口诀年龄不重新引入；如需提及高能量年改用本文 §五的 8 项门槛之一表述
- 流年立春日由排盘软件 / 万年历给出，不臆造

### 10.5 输出纪律

- 不下沉到月 / 日 / 时级
- 不写行动指引（按 prompt_大运十年详解 §三的边界）
- 不出助运推荐
- 已发生段口径偏"印证"，未发生段口径用"高概率""倾向于"——两者文笔差异须显式
- 模糊词禁用（§六.3）；可证伪点必备（§六.4）

## 十一、维护与迭代

### 11.1 修订动机

只有以下动机才修订本文档：

1. **8 项高能量年门槛与实证脱节**：从多命主跑测中识别出现有门槛遗漏 / 误纳——但门槛源在 `prompts/prompt_验前事.md` §5.2，本文档随之同步即可
2. **流年与大运叠加机制有更精的语言**：5 步链结构调整时
3. **格式约定调整**：产出文件结构演进时同步更新
4. **已发生段 vs 未发生段口径变化**：当前是"已发生段印证 / 未发生段高概率"，未来若发现统一口径更合理则调整
5. **多次跑测中观察到的"边界破洞"**：例如 prompt 字面已有约束但实操中持续越界（健康警示泛滥、内核反复无证伪、可证伪点过宽等）→ 升级为可操作的硬约束

### 11.1.1 修订记录

- **乙未三件套 + 甲午四件套两次跑测后的 P0 修订**（同一命主，2 个大运）：
  - §4.1 第 4 步追加"恒在背景音核对" + §八 Step 1 §0 边界声明追加"恒在背景音清单"——把大运层"整段 10 年都成立的钩子"显式入清单
  - §4.5 新增"流年支与运支的动 / 静两态"——把"冲运支" / "伏吟运支"两类机制并列入扫描维度
  - §6.4.1 新增"可证伪点的宽窄操作判定"——给出 30%-50% 区间作为目标证伪概率
  - §6.4.2 新增"不计入证伪判定的候选类型"清单——内核反复 / 健康轻中度警示 / 渐进型描述 / 倾向准备型描述 默认排除
  - §6.6 新增"健康警示的分级标准"——轻 / 中 / 重三级 + 滥用警告（中度 ≤ 4 / 重度 ≤ 2 per 大运）

### 11.2 不修订的情况

- 单次跑测命中度低 → 调整该次跑测的具体推断措辞，不改本文档
- 流派偏好变化 → 重大决定，应整体讨论
