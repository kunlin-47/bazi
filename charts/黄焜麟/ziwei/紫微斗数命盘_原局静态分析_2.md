## §3 生年四化轨迹

> 生年四化是紫微斗数中"先天能量的方向标记"——按生年天干推得，本造辛年生人四化为：**巨门禄、太阳权、文曲科、文昌忌**。本节逐条展开每个化的飞入位置 + 命理含义 + 与命盘其他结构的叠加。

### §3.1 巨门禄入子女宫（戌）

#### 结构事实
- **化**：禄
- **星**：巨门（北斗第二星，水星，化气为暗为是非为口才）
- **入宫**：子女宫戊戌
- **本宫主辅星**：巨门[陷]（生年禄激活）+ 擎羊[庙] + 红鸾[陷]
- **巨门同时是命主**——所以这是"命主带禄落子女宫"

#### 命理含义
- **巨门陷地 + 化禄**：巨门陷于戌（戌为火墓）本不得力，但生年禄激活后转为"暗中得财 / 暗中得利 / 是非中开口生财"——**陷地化禄是"看似不利但暗藏利"的结构**
- **同宫擎羊庙**：擎羊庙地是"用刃"——锐利但有用 → 配合巨门陷化禄，构成"暗中得利但伴锐利切割 / 是非"的特殊组合
- **命主巨门 + 生年禄落子女宫**：意味着命主"先天本命的能量出口"在**子女宫所辖的层面**——子女宫在紫微斗数中代表：
  - 子女缘 / 后代
  - 长期投入的大事 / 创作 / 输出
  - 学生 / 下属 / 受传承者
  - 性事 / 创造力本身

> 命主先天能量的"出口"不是"自我表达"（命宫无禄）、不是"婚姻"（夫妻无禄）、不是"事业"（官禄宫无生年禄，但有自化禄）、不是"财富"（财帛宫无生年禄，但有禄存）—— 而是 **"长期投入产出 / 创作 / 子女缘 / 输出"**。 [四化]

#### 多重叠加（命宫 + 福德宫的辛干四化也指向同位）
- 命宫宫干辛 → 巨门禄入子女宫（叠加 1）
- 福德宫宫干辛 → 巨门禄入子女宫（叠加 2）
- 生年辛 → 巨门禄入子女宫（叠加 3）

> **三重巨门禄入子女宫** —— 是命盘中能量集中度最高的吉端节点。命主"先天 + 主动 + 起心动念"三层都指向子女宫的"长期投入产出"维度。 [四化]

#### 但有反向冲突：财帛巨门忌入子女
- 财帛宫宫干丁 → 巨门忌入子女宫
- **三重生年禄 vs 财帛忌的对冲**：本造命盘最尖锐的禄忌交战之一

> 含义：命主的"长期投入产出"层面虽有先天大禄，但财帛的"动作"会撞向这个先天禄 —— 即**"为了长期投入产出而需要付出财力 / 财力流向长期产出"**——具体体现可能是：长期项目的"投入大于即时回报"、为创作 / 教学 / 长期输出投入财力、子女议题需要财力支持等。 [四化 + 飞星]

### §3.2 太阳权入交友宫（午）

#### 结构事实
- **化**：权
- **星**：太阳（中天主星，火星，化气为贵为权为外显）
- **入宫**：交友宫甲午
- **本宫主辅星**：太阳[旺]（生年权激活）+ 天钺 + 铃星[庙]

#### 命理含义
- **太阳旺地 + 化权**：太阳在午为旺地（午为太阳本位），化权后能量极强——"得权 / 主导 / 被推到台前"
- **入交友宫**：交友宫在紫微斗数中代表：
  - 朋友 / 同事 / 下属圈子
  - 上司 / 男性长辈 / 男性人际
  - 平辈关系网
- **太阳化权入交友**：**"在朋友 / 上司 / 男性圈子中得权 / 被推到主导位置"**

#### 但伴随双层自化：太阳 ↓忌 + ↑禄
本宫太阳同时有 **3 层四化叠加**：
- 生年权（外来）
- ↓忌（本宫宫干甲化太阳忌，太阳在本宫 → 离心自化忌）
- ↑禄（对宫兄弟宫宫干庚化太阳禄，太阳在交友宫 → 向心自化禄）

> **权 + 禄 + 忌三化叠加在同一颗太阳上**是非常稀少的结构 —— 含义是：
> 1. **生年权**：朋友圈中的主导力 / 权能（结构性）
> 2. **↑禄**：来自兄弟宫的"利益输入" —— 朋友 / 同辈带来的"实质好处"
> 3. **↓忌**：本宫自化忌 —— "得权后自我消解" —— 主导力会因为"自己的某种执着 / 不放松"而损耗

> 综合：**朋友 / 上司 / 男性圈子是命主的"权能 + 利益"集中场，但同时是"消耗 + 损耗"集中场** —— 即：**朋友圈给得多，但耗得也多**。 [四化]

#### 多重叠加（命宫 + 福德宫的辛干四化也指向同位）
- 命宫辛 → 太阳权入交友宫（叠加 1）
- 福德宫辛 → 太阳权入交友宫（叠加 2）
- 生年辛 → 太阳权入交友宫（叠加 3）

> 三重太阳权入交友宫 —— 命主在朋友圈 / 上司圈中的"主导力"是先天 + 主动 + 起心动念三层叠加的极强结构。但与 ↓忌 同时存在，使这种主导力不稳。 [四化]

### §3.3 文曲科入兄弟宫（子）

#### 结构事实
- **化**：科
- **星**：文曲（辅星，化气为科为才华为口才）
- **入宫**：兄弟宫庚子
- **本宫主辅星**：天梁[庙] + 文曲[得]（生年科激活）

#### 命理含义
- **文曲化科**：文曲是辅星中的"才华星 / 口才星 / 文采星"，化科后增强"名声 / 文采 / 才华显" —— "以才华得名 / 以口才扬名"
- **入兄弟宫**：兄弟宫在紫微斗数中代表：
  - 兄弟姐妹 / 同辈关系
  - 朋友 / 同事中较亲密的一层
  - 命主"出去后碰到的人"中较稳定的关系层

- **文曲科入兄弟**：**"在兄弟 / 同辈圈子中以才华 / 口才 / 文采出名"** —— 不是"在交友宫的泛泛之交中"，而是在**较稳定的同辈关系层**

#### 同宫天梁庙
- 天梁庙地是"长辈型护佑星" —— 主"得长辈 / 师长 / 贵人庇护"
- 天梁与文曲科同宫 → 兄弟宫整体气场是 **"才华 + 长辈型护佑 + 稳定关系"**
- 但本宫还有**阴煞** —— 阴煞主"暗中损耗 / 小人作祟" —— 给"才华 + 庇护"加上一层暗损

#### 多重叠加（命宫 + 福德宫 + 田宅 + 夫妻 都向兄弟宫飞入"科"）
| 来源 | 化 | 入宫 |
|---|---|---|
| 生年辛 | 文曲科 | 兄弟宫 |
| 命宫辛 | 文曲科 | 兄弟宫（叠加） |
| 福德宫辛 | 文曲科 | 兄弟宫（叠加） |
| 田宅宫壬 | 天梁禄 | 兄弟宫（注：天梁本身在兄弟） |
| 夫妻宫己 | 天梁科 | 兄弟宫（注：天梁科入兄弟） |
| 田宅宫壬 | 同时还会有... | （需细查） |

> 兄弟宫成为命盘中**"科 / 名声 / 才华辐射"的最强场** —— 命主在兄弟 / 同辈关系层有结构性的"才华 + 名声 + 长辈护佑"集中点。 [四化]

#### 但同时有夫妻宫文曲忌冲入
- 夫妻宫宫干己 → 文曲忌入兄弟宫（直接冲文曲生年科）
- 含义：婚姻 / 配偶层会**"忌冲"** 兄弟宫的文曲科——**婚后命主在兄弟 / 同辈圈中的"名声 / 才华显"会受婚姻议题的拖累**

> 这是一个微妙的能量节点：婚前命主可能在同辈圈中以才华 / 口才扬名（生年文曲科），但婚姻引入后会有结构性的"名声损耗" —— 不一定是公开的负面，可能只是"才华表达的频率 / 强度被婚姻议题分流"。 [飞星]

### §3.4 文昌忌入父母宫（寅）

#### 结构事实
- **化**：忌
- **星**：文昌（辅星，化气为科为学业为文运）
- **入宫**：父母宫庚寅
- **本宫主辅星**：无主星 + 文昌[陷]（生年忌激活）+ 天魁[庙]

#### 命理含义
- **文昌化忌**：文昌是辅星中的"学业 / 考试 / 文运 / 正规知识"星 —— 化忌后转为"学业受阻 / 文运不顺 / 知识获取层面有结构性卡"
- **文昌陷于寅**：寅为木地，文昌属金，金被木耗 —— 文昌在寅本就不强，化忌后更弱
- **入父母宫**：父母宫在紫微斗数中代表：
  - 父母 / 长辈
  - 学业 / 师承 / 正规教育
  - 上一辈传承下来的"福报 / 业力"
  - 文凭 / 学历 / 正规资质

- **文昌忌入父母**：**"学业 / 师承 / 文凭层面有结构性忌 + 父母层面有忌"**

#### 双层结构
父母宫无主星 + 文昌陷化忌 + 天魁庙 —— 整体气场复杂：
- **天魁庙**是贵人星 —— 主"长辈 / 师长 / 贵人提携"
- **文昌忌**是结构性忌 —— 主"学业 / 师承 / 文凭层有结构性卡"

> 这是**"贵人有但学业卡"** 的双层结构 —— 命主在父母 / 师承层 **能得到长辈赏识 / 贵人提携**（天魁庙），但同时在**正规学业 / 文凭 / 知识获取层有结构性阻力**（文昌忌）。 [三合 + 四化]

#### 但有自化救济：文昌 ↑科
- 对宫疾厄宫宫干丙 → 文昌科入父母宫（向心自化）
- 文昌生年忌 + 自化↑科 同时存在 → **"忌科同源"**

> 文昌忌科同源的命理含义：学业 / 师承层的结构性忌**会通过"内在思辨 / 健康 / 内核调整"（即疾厄宫所辖维度）反向化解为科**——含义是命主**"通过自我反思 / 内省 / 内在调整把学业上的卡转化为名声"** —— 不走"正规文凭 / 考试"路径，而走"自学 / 内省 / 体系化反思"路径。 [四化]

#### 三层叠加（最严重的结构性忌）
- 生年辛 → 文昌忌入父母宫（叠加 1）
- 命宫辛 → 文昌忌入父母宫（叠加 2）
- 福德宫辛 → 文昌忌入父母宫（叠加 3）

> 文昌忌**三重叠加在父母宫** —— 是本造命盘**最严重的结构性忌** —— 比单次生年忌严重得多。命主在学业 / 师承 / 父母层 **先天 + 主动 + 起心动念三层都带忌** —— 但同时有疾厄宫向父母飞入↑科 —— **解忌的路径是内省 / 内核调整** —— 不是外部资源 / 学校 / 文凭。 [四化]

#### §3.5.1 四化飞入位置统计

## §4 自化结构（7 处自化的拓扑）

> 自化是四化派的精微分析维度。本造命盘共有 7 处自化（3 处 ↓离心 + 4 处 ↑向心），是命盘中能量进出最频繁的层级。

### §4.1 ↓离心自化（3 处：本宫宫干化本宫主辅星）

#### §4.1.1 破军 ↓禄（官禄宫癸 → 破军禄）
- **结构**：官禄宫宫干癸的四化中破军禄，破军在官禄宫 → 本宫自化禄
- **离心禄的命理含义**：能量从本宫"流出"——是"得而易失" / "禄气浮在表面" / "不真实的得"
- **作用对象**：事业 / 立命之业
- **含义**：事业的"得"会自我消解 —— 命主在事业上**容易得到机会但也容易因自我原因（不珍惜 / 重新选择 / 推倒重来）而失去**
- **与破军本身"破立"特性叠加**：使事业呈**"频繁开局 + 频繁推翻"**的倾向
- **当前大限第3限己亥** 大限四化 = 武曲禄 / 贪狼权 / 天梁科 / 文曲忌 → 大限四化中无破军直接进入官禄宫，但 25-34 这段期间，离心禄的"得而失"特性仍恒在背景音

#### §4.1.2 太阳 ↓忌（交友宫甲 → 太阳忌）
- **结构**：交友宫宫干甲的四化中太阳忌，太阳在交友宫 → 本宫自化忌
- **离心忌的命理含义**：能量从本宫"忌出" —— "自带损耗 / 自己给自己使绊"
- **作用对象**：朋友 / 上司 / 男性人际
- **含义**：朋友圈 / 上司关系中**"自己给自己使绊"** —— 不是别人对命主不好，而是命主在朋友圈中**因为某种自身原因**（如过度自我中心 / 过度独立 / 过度直接）而损耗朋友关系
- **与生年权 + ↑禄叠加**：太阳化权 + ↑禄 + ↓忌 三化共在 —— 朋友圈是命主的"权能 + 利益 + 自损"集中场 —— 是高能量但高消耗的关系层

#### §4.1.3 天机 ↓权（疾厄宫丙 → 天机权）
- **结构**：疾厄宫宫干丙的四化中天机权，天机在疾厄宫 → 本宫自化权
- **离心权的命理含义**：权从本宫"流出" —— "权浮于表面 / 权而不实 / 自己给自己赋权"
- **作用对象**：身心健康 / 内在思辨 / 身主能量
- **含义**：命主**自己给自己赋权** —— 思辨 / 内省 / 内在调整这件事**靠自己推动而非外部推动**
- **与身主天机叠加**：身主在疾厄 + 自化权 → 命主"立身的内在驱动力源"是**自我推动型** —— 不靠外部环境逼迫，而靠**对内的不满 / 对思辨的执着 / 对内核的不放过**
- **与 §1.3.2 身主分析一致**：是命主"内驱型"特质的核心结构性证据

### §4.2 ↑向心自化（4 处：对宫宫干化本宫主辅星）

#### §4.2.1 武曲 ↑禄（夫妻宫己 → 武曲禄入官禄）
- **结构**：对宫夫妻宫宫干己的四化中武曲禄，武曲在官禄宫（本宫即身宫）→ 向心自化禄
- **向心禄的命理含义**：禄从对宫"飞入" —— "对宫给本宫送禄" —— 实质性吉端
- **作用对象**：事业 / 立命之业 + 夫妻宫的"配偶 / 婚姻"
- **含义**：**婚姻 / 配偶为事业带来禄** —— 是经典的"妻助事业"（男命）/"妻荣夫贵" 的结构性证据

> 与 §3.2 太阳权入交友宫 ↓忌 ↑禄叠加结构相比 —— 武曲↑禄的"实质性吉端"程度更高（因为没有 ↓忌 同时存在）。

#### §4.2.2 文昌 ↑科（疾厄宫丙 → 文昌科入父母）

#### §4.2.4 太阴 ↑科（父母宫庚 → 太阴科入疾厄）

### §4.3 自化总评

#### §4.3.1 自化的方向偏好
- **3 处↓离心**：破军 / 太阳 / 天机 —— 都是动星类 / 主星类 / 身主类 —— **"主动能量的自我消解"**

> 7 处自化中**↑向心多于↓离心** —— 命盘整体的能量流向是**"对宫给本宫送 > 本宫自我消解"** —— 是吉端略多于忌端的能量结构。 [四化]

#### §4.3.2 自化的宫位分布

> 自化集中在 4 个宫位上：**官禄（身宫）/ 疾厄 / 交友 / 父母** —— 这 4 个宫位是命盘的"能量进出最频繁的高耗点" —— 与 §2.7.2 能量集中点统计完全一致。 [四化]

#### §4.3.3 7 处自化的命理总轴

- **疾厄宫**权进科出（实际是权出科入） → 内在思辨是命主"自我推动 + 接受外援"的双向场

> 综合：本造命主的 4 个高能量宫位都是**"双向高强度能量交换"**型 —— 不是"稳定收益"型 —— 一生在事业、内在、朋友、学业四层都会经历"高能量进出" —— 是**"丰富 + 复杂 + 起伏"**的命主类型，不是"平稳 + 单一"的命主类型。 [四化]

> 夫妻宫"不被四化激活"的命理含义：**婚姻关系不是命盘中"被多向能量驱动"的场** —— 婚姻的好坏**主要由本宫主辅星 + 本宫飞出决定**，而不被外宫激活。 [四化]

#### 本宫宫干飞向他宫（己四化）
- **武曲禄 → 官禄宫**（**武曲↑禄入身宫！**）—— 婚姻为事业送禄
- **贪狼权 → 财帛宫** —— 婚姻为财帛送权
- **天梁科 → 兄弟宫** —— 婚姻为兄弟送科
- **文曲忌 → 兄弟宫** —— **婚姻为兄弟送忌（冲生年科！）**

> 夫妻宫**向官禄、财帛、兄弟（科 + 忌同位）** 飞出 —— 是命盘中**"夫妻能量向外辐射"的核心节点**。 [飞星]

#### 关键观察：夫妻 → 兄弟的科 + 忌同位
- 夫妻宫向兄弟宫同时飞天梁科 + 文曲忌
- 兄弟宫的天梁本身得天梁科（吉），文曲本身得生年科（吉）
- 但夫妻宫送的文曲忌**直接冲文曲生年科**

> 含义：**婚姻引入后**，命主**在兄弟 / 同辈圈中的"才华扬名"会受冲击** —— 不是天梁科的部分（天梁层面婚姻是加分的），而是**文曲层面**（即"才华表达 / 口才"层面）。

> 具体可能的表现：婚后命主在朋友 / 同辈圈中的"个人表达频率 / 个人才华展示"会受婚姻议题分流 —— 这不是"婚姻坏"而是**"婚后的能量重心结构性转移"** —— 是命理上的客观结构，不构成"应该不结婚"的依据。 [飞星]

#### 综合判断
- **气场**：得贤助 + 但有动 + 急 / 烈 + 突变
- **核心特质**：婚姻有协调有助但不安于一处
- **关键功能**：**婚姻是事业的"禄源"** —— 配偶为命主立身之业带来实质性吉端
- **隐性议题**：
  - 婚姻给兄弟 / 朋友圈带来"才华表达分流"
  - 事业不向夫妻宫回流（§5.3.2）
- **当前大限**：25-34 虚岁是夫妻宫大限 —— 婚姻议题是命主**当前 10 年的核心命运主轴** —— 与八字盘"乙未运 19-29 + 甲午运首段 29-39"在时间上**完全交叉**

> 夫妻宫大限是命主当前正在走的限期 —— 紫微的事件类型清单（婚姻议题密集 / 配偶进入 / 婚姻为事业带禄）与八字盘对应大运（乙未运妻星首透 / 甲午运妻星明位再透）的事件类型清单**同向印证**（仅作旁证，不修改八字结论）。 [三合 + 四化 + 飞星]

### §6.4 子女宫（戊戌）

#### 宫位事实
- 地支：戌（西方火墓库）
- 宫干：戊
- 主星：巨门[陷，**生年禄**]
- 辅星：擎羊[庙] · 红鸾[陷]
- 小星：天寿[庙] · 封诰 · 大耗[平] · 月德 · 孤辰
- 大限段：35-44 虚岁（第 4 大限）

#### 主辅星组合
- **巨门陷 + 生年禄**：陷地化禄是"暗中得财 / 暗中开口生财"
- **擎羊庙**：用刃 + 锐利 + 但庙地为"用得起的锐利"
- **红鸾陷**：桃花星陷地 → 桃花有但弱
- **大耗 + 孤辰 + 天寿庙**：复杂混杂的小星

#### 飞入本宫的四化（命盘的"吉端能量集中点"）
| 来源 | 化 | 星 |
|---|---|---|
| 生年辛 | 巨门禄（叠加 1） | 巨门 |
| 命宫辛 | 巨门禄（叠加 2） | 巨门 |
| 福德宫辛 | 巨门禄（叠加 3） | 巨门 |
| 官禄宫癸 | 巨门权 | 巨门 |
| 子女宫戊 | （本宫宫干飞出） | — |
| **财帛宫丁** | **巨门忌** | **巨门**（直接冲生年禄） |

> **三重生年禄 + 一重权 + 一重忌** 集中在巨门一颗星上 —— 是命盘中**能量最稠密**的单星节点。 [四化]

#### 本宫宫干飞向他宫（戊四化）
- **贪狼禄 → 财帛宫**（子女送禄给财帛！）
- 太阴权 → 疾厄宫
- 右弼科 → 福德宫
- **天机忌 → 疾厄宫**（子女送忌给疾厄！）

> 子女宫向**财帛、疾厄（双向）、福德** 飞出 —— 子女宫的能量向外辐射到财、内省、思想三层。 [飞星]

#### 关键观察：子女 → 财帛 的禄 vs 财帛 → 子女 的忌
- 子女送禄给财帛（贪狼禄入财帛）
- 财帛送忌给子女（巨门忌入子女）

> 这是**双向交换** —— 命主"长期投入产出"与"财富"两个层面**互相喂养 + 互相消耗**：
> - 长期投入产出会带来财富（子女→财帛禄）
> - 但财富的"动作"会反过来撞击长期投入产出（财帛→子女忌冲生年禄）
> - **结果**：命主在"长期投入产出"层面有结构性的吉端，但需要**"不让财力的现实压力撞击长期投入"** —— 即需要在某个程度上把"长期投入"与"短期现金流"分开

#### 综合判断
- **气场**：暗中得利 + 用刃锐利 + 桃花弱 + 复杂小星
- **核心特质**：**命主先天能量最强的"出口"** —— 子女缘 / 长期投入产出 / 创作 / 输出 / 学生 / 性事
- **能量集中**：三重禄 + 一权 + 一忌 + 命主巨门坐此 —— 是命盘中能量最稠密的单宫
- **隐性议题**：财力压力会撞击长期投入产出
- **当前 25 岁状态**：35-44 是第 4 大限，命主在此年龄进入子女宫大限 —— 紫微的"子女宫大限"在时间上**与八字甲午运（29-39）的中段 + 癸巳运的前段**对应

> 子女宫是本造命盘的"能量主出口" —— 命主一生中有两次主要的"激活"：
> 1. **当前不激活**：因为命主当前在第 3 大限（夫妻宫）
> 2. **35-44 大激活**：第 4 大限直接落在子女宫 —— 命主进入子女宫大限时，三重生年禄 + 命主巨门 + 擎羊庙的能量会被**结构性放大**
> 3. 与八字甲午运 §第三步关键提醒"立家立业窗口 + 婚姻 / 子女 / 长期事业...在这十年最有结构支撑"**同向印证**（仅作旁证，不修改八字结论） [三合 + 四化]

### §6.5 财帛宫（丁酉）

#### 宫位事实

- 宫干：丁
- 主星：紫微[旺] · 贪狼[利]

- 小星：龙池[庙] · 天官[平] · 旬空[庙] · 破碎[平]
- 大限段：45-54 虚岁（第 5 大限）

#### 主辅星组合（详见 §2.3）
紫贪在酉 + 禄存 —— 财上有"主帝主 + 守财星"双护，但有旬空 + 破碎的"耗"。

#### 飞入本宫的四化

> 财帛宫接受**禄、权（双重）、科、忌**——四化全到 —— 是命盘"能量进入最复杂"的宫位之一。 [四化]

#### 本宫宫干飞向他宫（丁四化）
- 太阴禄 → 疾厄宫
- 天同权 → 田宅宫
- 天机科 → 疾厄宫
- **巨门忌 → 子女宫**（**直接冲生年禄！**）

#### 关键观察：财帛宫的"出"是高强度
财帛宫向**疾厄（双向：禄 + 科）、田宅、子女（忌）** 飞出 —— 财帛宫是**"高强度向外送能量"**的宫位 —— 但其中"巨门忌冲子女生年禄"是结构性的内耗节点。 [飞星]

#### 综合判断
- **气场**：紫微旺 + 贪狼利 + 禄存庙 + 旬空 + 破碎
- **核心特质**：**财上偏稳** —— 紫微 + 禄存的双护使财不易大失
- **隐性议题**：
  - 旬空 + 破碎使"账面富足但实际感觉空一段"
  - 事业向财帛冲忌（贪狼忌）—— 事业层面的"动"会冲击财稳
  - 财帛向子女冲忌（巨门忌）—— 财力压力会撞击长期投入
- **婚姻送权**：夫妻贪狼权入财帛 —— 婚姻为财帛带来"权 / 主导力"
- **45-54 第 5 大限**：财帛宫直接成为大限 —— 命主中年期财富议题密集

> 财帛宫是命盘中"庙旺度 + 四化复杂度"双高的宫位 —— 命主一生在财富议题上**结构稳健但事件起伏密集** —— 不是"穷困型"也不是"暴富型"，而是**"稳基底 + 高频动"**型。 [三合 + 四化]

### §6.6 疾厄宫（丙申）

#### 宫位事实
- 地支：申（西方金 + 长生位）
- 宫干：丙
- 主星：天机[得，**↓权**] · 太阴[利，**↑科**]
- 辅星：陀罗[陷] · 天姚[陷]
- 小星：天使[平] · 副旬[庙] · 孤辰[平]
- 大限段：55-64 虚岁（第 6 大限）

#### 主辅星组合
- **天机得 + 太阴利**：机阴组合是经典的"思辨 + 阴柔之知"组合 —— 主"心思敏感 + 思虑多 + 情绪波动 + 内在反复"
- **陀罗陷**：煞星陷地 → 慢病 / 缠斗 / 纠缠 / 不利索
- **天姚陷**：桃花星陷地 → 多情 / 流连 / 自我消耗
- **机阴 + 陀罗 + 天姚** 的组合：**"思辨敏感 + 慢病纠缠 + 自我消耗"** —— 健康 / 内在层面是命盘**最复杂的能量场**

#### 飞入本宫的四化（命盘"能量最稠密"宫位之一）
| 来源 | 化 | 星 |
|---|---|---|
| 财帛宫丁 | 太阴禄 | 太阴 → 疾厄 |
| 财帛宫丁 | 天机科 | 天机 → 疾厄 |
| 迁移宫乙 | 天机禄 | 天机 → 疾厄 |
| 子女宫戊 | 太阴权 | 太阴 → 疾厄 |
| 兄弟宫庚 | 太阴科 | 太阴 → 疾厄（向心↑科入疾厄） |
| 父母宫庚 | 太阴科 | 太阴 → 疾厄（向心↑科入疾厄；与兄弟同庚） |
| 子女宫戊 | 天机忌 | 天机 → 疾厄 |
| 迁移宫乙 | 太阴忌 | 太阴 → 疾厄 |
| 疾厄宫丙 | 天机权（↓） | 天机 → 疾厄（自化权） |

> **疾厄宫接受 9 重四化** —— 是命盘**能量最稠密**的宫位（超过子女 + 官禄）。其中：
> - 天机：禄 + 科 + 忌 + ↓权 —— 4 化全到
> - 太阴：禄 + 权 + 科（双重）+ ↑科 + 忌 —— 5 化（科四重）
> - **太阴的"科"集中度极高** —— 内省 / 思辨 / 内核调整在"科 / 名声 / 才华"层面被高密度赋能 [四化]

#### 本宫宫干飞向他宫（丙四化）
- 天同禄 → 田宅宫
- 天机权 → 本宫（↓自化）
- **文昌科 → 父母宫**（向心↑科入父母 —— 解父母文昌生年忌的关键路径）
- 廉贞忌 → 命宫

#### 关键观察：疾厄宫是命盘的"内省 / 思辨 / 内核调整"中枢
- 接受 9 重四化（最高密度）
- 向父母送科（解忌）+ 向命宫送忌（影响自我）
- 太阴 + 天机两颗主星的庙旺度都不极强（得 + 利）—— 但**靠四化多重叠加补强**

> 疾厄宫的命理重要性：
> 1. 是身主天机的所在宫
> 2. 是 9 重四化集中的能量中枢
> 3. 是 ↓权 + ↑科 双自化的进出场
> 4. 是命盘"内省 / 思辨 / 内核调整"的总枢
> 5. 是解 §3.4 父母文昌忌的关键路径源
>
> **整个命盘的"内省主导型"特质都根植于此**。 [四化]

#### 综合判断
- **气场**：思辨敏感 + 慢病纠缠 + 多情消耗 + 极高强度四化进出
- **核心特质**：**命盘的"内省 / 思辨"中枢** —— 命主一生"对内的思考 / 调整 / 反复"的能量根源
- **隐性议题**：
  - 陀罗 + 天姚陷的"慢病 / 自我消耗"是结构性的（与八字盘"伤官当令 + 内核摇晃"同向旁证）
  - 9 重四化使疾厄宫"高强度但易疲倦"
  - 健康层面需要警惕：神经系统 / 思虑性疾病 / 慢性 / 情志类（紫微角度的提示，**以医生建议为优先**）
- **55-64 第 6 大限**：疾厄宫直接成为大限 —— 命主中老年期健康议题密集

> 疾厄宫是命盘"内驱型命主"的命理依据 —— 与 §1.3.2 身主天机分析、§4.1.3 天机↓权分析、§2.6 命宫与福德宫张力分析 共同构成命主"内驱 + 内省 + 内核反复"的命理三脚架。 [三合 + 四化]
