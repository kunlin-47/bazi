### §1.3 命主 / 身主 / 命宫 / 身宫 / 来因宫 速读

#### §1.3.1 命主：巨门（陷于子女宫戌，生年禄）

紫微斗数中"命主"按生年支推得，主管"先天本命的核心能量倾向"。本造命主巨门——

- **巨门**：北斗第二星，五行属水，化气为暗、为是非、为口舌——但同时也是**辨识 / 思辨 / 口才 / 深度沟通**的星
- **巨门陷于戌**：戌为火墓库，水星巨门坐火地不得令——巨门陷地的"暗 / 是非"属性被强化
- **生年禄入巨门**：但同时辛年生年禄飞入巨门——"暗中得财 / 暗中有利 / 是非中开口生财"——把"陷地暗星"转化为"暗中得利的口才之星"
- **同宫擎羊庙**：擎羊庙地是"用刃"——为巨门陷的是非属性配上"用得起的锐利"——是"暗中开口 + 锐利切割 + 但伴是非"

> 命主巨门坐子女宫的位置含义：命主"先天能量在子女 / 长期投入的大事 / 创作 / 输出"层面有结构落地点——这是**先天本命的能量出口**——不是说命主"先天关心子女"，而是命主"先天的能量倾向"在"长期开口 / 长期投入产出"上有落点。 [三合 + 四化]

#### §1.3.2 身主：天机（得于疾厄宫申，自化权 ↓权 + 飞入太阴 ↑科）

身主按生年支推得，主管"后天行动 / 立命之业的内在驱动"。本造身主天机——

- **天机**：南斗第三星，五行属木，化气为善、为智慧、为善变——是"思辨 / 计算 / 智略 / 灵活"的星
- **天机得于申**：申为金地，木气在金中受克但有"金克木成材"的转化——天机得地，主"思辨之器在结构性外部环境中被磨砺成器"
- **自化权 ↓**：本宫宫干丙化天机权，权回到本宫——"思辨能量被自我推动"——不是被外部赋权，而是**自己给自己赋权**
- **飞入太阴科 ↑**：对宫父母宫宫干庚化太阴科，太阴在本宫——"父母 / 师承 / 上一辈的'温润 / 阴柔之知'被注入到自我思辨中"

> 身主天机坐疾厄宫的位置含义：命主"后天行动的驱动力源"在"疾厄宫所辖的健康 / 情绪 / 内在调整 / 思虑"层面——这意味着命主的"立命动力"很大程度上**不是外部推动型**（不是"被环境逼出来的奋斗"），而是**内在自我推动型**（"对内在不满 / 对思辨的执着 / 对内核的不放过"驱动）。 [三合 + 四化]

#### §1.3.3 命宫：廉杀坐丑（无辅星 + 天哭 + 华盖陷）

- **廉贞[利] + 七杀[庙]**：双主星，七杀庙强于廉贞利 → 七杀主导
- **七杀**：南斗第六星，化气为权、为将、为肃杀——"独立 / 决断 / 不畏挑战 / 自带威严感"
- **廉贞**：北斗第五星，化气为囚、为次桃花、为次官禄——"理性 / 锐利 / 但有人际感"
- **廉杀同宫坐丑**：丑为湿土库，廉杀同坐丑未两宫是经典格——古典断"积富之人 / 权杀加身 / 但需经历险阻方成"
- **无辅星**：命宫无左辅 / 右弼 / 文昌 / 文曲 / 天魁 / 天钺等辅星——意味着命主**自我承担**而非"被辅佐"——独立性强但孤援少
- **天哭[庙] + 华盖[陷]**：天哭庙主"忧思 / 多感 / 深沉"；华盖陷主"清高 / 孤独 / 但陷地为弱——清高有但不极端"

> 整体气场：杀气重 + 锐利 + 独立 + 深沉忧思 + 略带清高——廉贞的"理性 / 桃花"被七杀的肃杀气压制，命主表现为"务实型杀气"而非"情感型桃花"。 [三合]

#### §1.3.4 身宫：巳（与官禄宫同宫，武破）

紫微斗数中"身宫"是出生时辰决定的，与命宫并行——命宫是"先天本性 / 内在自我"，身宫是"后天行动 / 立命之业 / 老来归宿"。

本造**身宫与官禄宫同宫**——这是十二宫中身宫可能落入的六个位置（命宫 / 夫妻 / 财帛 / 迁移 / 官禄 / 福德）之一——**身宫坐官禄 = 命主"以事业立身"**。

> 身宫坐官禄的命主，行动方向 / 立命之业的核心权重在"事业 / 长期投入的工作 / 社会角色"——不是以家庭、感情、财富、思想为立身之本，而是以"做出一番事 / 在某个领域立身"为本。 [三合]

身宫的星象是**武曲[平] + 破军[平]**，加上**武曲↑禄（夫妻飞入）+ 破军↓禄（本宫自化）**——具体在 §2.4 详述。

#### §1.3.5 来因宫：福德宫辛卯（与命宫同辛干）

来因宫是十二宫中"宫干与命宫宫干相同"的那一宫（命宫辛丑、福德宫辛卯，同辛）——主"命主大事的因 / 起心动念之处 / 一切大事的源头"。

本造来因宫落福德——

- 福德宫无主星 → 借对宫财帛宫紫贪入福德
- 福德宫坐右弼[陷] + 地空[平] —— 思维根基偏空 + 借势 + 地空的虚化作用
- **来因宫 + 福德宫的合一**：意味着命主"一切大事的根源"在**思想 / 信念 / 习气 / 内核状态**层——不在具体的人事物上

> 来因落福德的命主，命理上的特点是"想法决定行动"——做某件大事 / 走某条路，根源往往不是外部条件促成，而是"心里想清楚了 / 信念坚定了 / 习气把人推到那里" → 是**内驱型命主**。 [三合 + 四化派的"来因宫"理论]

> 与命宫"廉杀杀气重"对照：**思想根基（福德空劫飘）vs 行动力（命宫廉杀决断）** —— 这是一个内在的张力结构，§2.6 单独展开。

## §2 核心结构识别

> 本节给出 7 条命盘核心结构判断，类似八字静态分析中的 `_meta.core_judgments` —— 是后续 §3-§7 一切细节分析的母版。

### §2.1 命宫廉杀坐丑（核心格局之一）

#### §2.1.1 结构事实
- 命宫地支丑（湿土库）+ 宫干辛
- 主星：廉贞[利] + 七杀[庙]
- 辅星：无
- 小星：天哭[庙] + 华盖[陷] + 三台
- 命宫宫干辛 → 辛四化（巨门禄、太阳权、文曲科、文昌忌）—— **命宫宫干四化与辛年生年四化完全一致**（因生年与命宫同辛）→ 命宫的"动作四化"与"先天能量四化"**同向叠加**

#### §2.1.2 经典断语对照
- "廉杀坐丑未" —— 古典格局，论"权势加身但需经历险阻方成"，"积富之人但前期险" —— 含义：**命主先天有"权"的格局基础，但必经险阻后方显** [三合]
- "七杀庙地为权" —— 七杀庙旺时不是"凶星"而是"将星" —— 主独立、决断、自带威严 [三合]
- "廉贞次桃花次官禄"被七杀压制 —— 廉贞的"次桃花"特性在与庙地七杀同宫时被肃杀气压制，转化为"理性 + 决断" [三合]

#### §2.1.3 命宫四化叠加
命宫宫干辛与生年辛同字 → 巨门禄、太阳权、文曲科、文昌忌 四化的飞入路径**双层叠加**：
- 巨门禄入子女宫（双层 → 命主先天能量 + 命宫主动四化都指向"长期投入的大事"）
- 太阳权入交友宫（双层 → 朋友 / 上司 / 男性长辈圈是命主"先天 + 主动"的权能场）

> 命宫四化与生年四化完全同字叠加是辛年命宫坐丑 / 卯 / 巳 / 未 / 酉 / 亥（六阴宫）的特殊现象 —— **本造命主属于此结构** —— 意味着命主"先天倾向"与"主动作意"高度一致，没有"内外背离"的张力，但也意味着"先天弱点"会在主动行为中被双倍放大（特别是文昌忌入父母）。 [四化]

### §2.2 杀破狼联动（核心格局之二）

#### §2.2.1 结构事实
- 命宫：**七杀**[庙]（丑）
- 官禄宫 / 身宫：**破军**[平]（巳）
- 财帛宫：**贪狼**[利]（酉）
- 三方四正中三个核心宫位**全是杀破狼三星** —— 这是紫微斗数中典型的"杀破狼格局"

#### §2.2.2 杀破狼的命理意义
- **杀破狼是"动星组合"** —— 三星都主"变动 / 突破 / 不稳但有大势" [三合]
- 七杀主"将权 / 决断 / 独立"
- 破军主"破耗 / 创新 / 推倒重来"
- 贪狼主"欲望 / 多元 / 桃花 / 但也有进取气"
- **三星联动** —— 命 / 官 / 财三方都在动 → 命主一生在"行动 / 事业 / 财富"三层都不会"安稳止步"——必有结构性的变动 / 突破 / 起伏

#### §2.2.3 三星庙旺度的差异
- 七杀庙（命宫）→ 命主的"将权 / 决断"层最强
- 破军平（官禄宫）→ 事业的"破立"层中等，需要靠辅星与四化力增强
- 贪狼利（财帛宫）→ 财富的"多元 / 进取"层不弱但不极强

> **能量峰在命宫 → 命主先天行动力极强，但事业（破军平）和财富（贪狼利）的执行落地稍弱于命宫的发起力** —— 这是一个"想得快 + 决断猛 + 但落地需要积累"的结构。 [三合]

#### §2.2.4 紫府对照
- 财帛宫：紫微[旺] + 贪狼[利]
- 迁移宫：天府[庙]
- 紫微（财）↔ 天府（迁）形成"紫府对照"——**杀破狼三星之间被紫府二主（紫微 + 天府）调控**

> 紫府对照在杀破狼格局中起"约束 / 调控 / 稳定"作用——使"动星的破立"不至于失控 → 命主的变动有"上限 / 框架 / 节制"，不会变成纯粹的破坏型变动。 [三合]

#### §2.2.5 紫府夹动的命理意义
- 紫微 + 禄存在财帛宫（酉，紫微旺 + 禄存庙）→ 财上有"主帝主 + 守财星"双护
- 天府庙在迁移宫（未）→ 外缘 / 出门远行 / 社会层面有"府库稳定"
- 但财帛宫有**旬空[庙]**——使财上"看似稳但有空一段"的体感
- 迁移宫有**地劫[平]**——使迁移 / 远行有"得有失"

> **紫府对照 + 杀破狼联动**的整体格局：
> - 命主一生的事业 / 财富 / 行动**会动会变**（杀破狼）
> - 但**有大方向的稳定（紫府）**
> - 同时**财空 + 迁劫**带来"看似稳但实际有耗 / 看似动但实际有失"的双层体感
> - 这是经典的"格局有 + 但需经历起伏方显"格 [三合]

### §2.3 紫贪 + 禄存在财帛（核心格局之三）

#### §2.3.1 结构事实

- 主星：紫微[旺] + 贪狼[利]
- 辅星：禄存[庙]
- 小星：龙池[庙] + 天官[平] + **旬空[庙]** + 破碎[平]

#### §2.3.2 紫贪在酉的格局
- "紫贪同宫" —— 经典格"桃花犯主"（紫微为帝主，贪狼为桃花，同宫则有"主星偏桃花"之倾向）
- 但"桃花犯主"在**酉宫**有特殊性——酉为西方金气最盛之地，紫微旺、贪狼利于此 → "桃花犯主"被金气节制，转化为**"统帅气场 + 多元欲望但不滥"**

#### §2.3.3 紫微旺 + 禄存庙
- **紫微旺**：北斗主星紫微在酉为旺地（紫微在子午为庙、卯酉为旺、巳亥为得） → 财帛宫有"主帝主"坐镇
- **禄存庙**：禄存为生年禄的"伴星"（辛年禄存在酉），庙地禄存是"强力守财星"
- **紫微 + 禄存**：经典"紫府禄存"格的变体（虽不是紫府而是紫贪）—— 财上有"中宫主星 + 守财星"双护 → **财上偏稳**

> 紫微 + 禄存同宫的财帛是"君主守财库" —— 主守得住、经得起耗。 [三合]

#### §2.3.4 旬空 + 破碎的"耗" 因素
- **旬空[庙]**：旬空（甲午旬中辰巳为旬空，2001 年命主属辛巳生人——其旬空判定：辛巳年生在何旬中需精算，但软件标注酉为旬空[庙] / 戌为孤辰、戌中藏的是命主巨门，那么这里"旬空"应是按子年斗君配套的旬空标记）—— **旬空主"实质上有但局部空"**
- **破碎[平]**：破碎是"小耗" —— 主"破财不大但常有"

> 财帛宫的**旬空 + 破碎**与"紫微 + 禄存"的稳定形成张力：**结构上稳，但实际拥有体感不如结构暗示** —— 命主可能有"账面富足但实际感觉空一段"的体感。 [三合 + 飞星]

#### §2.3.5 财帛宫的飞星拓扑

  - 太阴禄入疾厄宫（财源由"内核 / 心思 / 健康"输出 → 即靠思辨 / 内省得财）

### §2.4 身宫武破在巳（核心格局之四，最复杂的能量交汇点）

#### §2.4.1 结构事实
- 身宫坐巳（与官禄宫同宫）+ 宫干癸
- 主星：武曲[平] + 破军[平]
- 辅星：无
- 小星：凤阁[庙] + 天福[旺] + 截空[庙] + 年解[旺]

#### §2.4.2 武破在巳的格局
- "武破巳亥" —— 经典格，武破二星同坐巳或亥宫 —— 武曲为正财将 + 破军为变动星，"财与破"的张力
- 武破在巳，巳为火地（南方火气最盛）—— 武曲属金，破军属水，金水同坐火地 → **金被火克 + 水被火耗** —— 双星都受地支克
- 因此武曲 + 破军在巳都是**平地** —— 双星本身的力量都不极旺

#### §2.4.3 双星都需"四化补强"才能成器
本造身宫武破有 **5 重四化叠加**——是命盘中四化最稠密的宫位：

|---|---|---|---|---|
| 1 | 本宫宫干癸 | **破军禄** | 本宫破军（↓禄） | 事业的"得"会自我消解（离心自化禄主"得而失"） |
| 2 | 对宫夫妻己 | **武曲禄** | 本宫武曲（↑禄） | 配偶 / 婚姻为事业带来禄（吉端） |

#### §2.4.4 四化方向解读
- **禄**：武曲↑禄（夫妻吉）+ 破军↓禄（本宫自化耗） → **禄的进与出同时存在** —— 事业上"得"很容易但也"耗"很容易
- **忌**：武曲忌（田宅冲入） → 家庭议题会成事业的拖累
- **权 + 科**：破军权 + 武曲科（交友飞入） → 朋友 / 圈子能给事业带来权与名 —— **朋友圈是事业的关键支援源**
- **离心自化禄（破军↓禄）的特殊性**：这种自化是"事业本身的能量在自我消解" —— 命主在事业上**容易得到机会，但也容易因自我原因（不珍惜 / 重新选择 / 推倒重来）而失去** —— 与破军本身"破立"特性叠加，使事业呈现"频繁开局、频繁推翻"的倾向

#### §2.4.5 身宫的小星组合
- **凤阁[庙]**：庙地凤阁主"名望 / 文采 / 高雅风范"——身宫得凤阁庙 → 命主立身有"名望 / 风范"潜质
- **天福[旺]**：旺地天福主"福气 / 顺缘 / 长寿" —— 身宫得天福旺 → 立身有福气底色
- **截空[庙]**：庙地截空主"中断 / 暂停 / 阶段性结束" —— 身宫得截空庙 → 立命之业**会有结构性中断 / 阶段性结束**
- **年解[旺]**：旺地年解主"化解 / 转危为安" —— 身宫得年解旺 → 立命之业有"困境化解"潜质

> 身宫的小星组合：**名望 + 福气 + 阶段性中断 + 化解** —— 暗示命主一生立命之业的轨迹是"得名望 + 有福气 + 但有中断 + 终能化解"的循环型结构。 [三合]

#### §2.4.6 身宫的"夫妻 ↔ 官禄"轴心
本造命盘中**最重要的飞星轴线**：

```
夫妻宫（己亥）—— 武曲禄 ——→ 官禄宫 / 身宫（癸巳）
夫妻宫（己亥）—— 文曲忌 ——→ 兄弟宫（庚子）
官禄宫（癸巳）—— 巨门权 ——→ 子女宫（戊戌）
官禄宫（癸巳）—— 贪狼忌 ——→ 财帛宫（丁酉）
```

> 夫妻宫向身宫飞武曲禄是经典的"配偶助事业" —— 但夫妻宫同时向兄弟宫飞文曲忌（朋友 / 才华层有损耗），且官禄宫向财帛宫飞贪狼忌（事业向财帛带忌）—— **整个轴线的能量进出复杂**：婚姻给事业带来禄，但事业也耗财、并且婚姻给朋友圈带来忌。

> 这是命盘中**婚姻 ↔ 事业 ↔ 财富 ↔ 朋友** 四宫强烈交织的核心结构，命主一生的核心议题大概率围绕这四个层面展开。 [四化 + 飞星]

### §2.5 来因落福德 + 福德空劫（核心格局之五）

#### §2.5.1 结构事实
- 福德宫地支卯 + 宫干**辛**（与命宫同辛干 → 福德宫为来因宫）
- 主星：无 → 借对宫财帛宫的紫微 + 贪狼入福德
- 辅星：右弼[陷] + 地空[平]
- 小星：无（罕见的"无小星"宫位）
- 福德宫宫干辛 → 辛四化（巨门禄、太阳权、文曲科、文昌忌） —— 与命宫四化、生年四化**三层叠加**

#### §2.5.2 来因宫的命理意义（非首段大运对偶机制的紫微版本）
来因宫是"命主大事的因"——一切大事的源头追溯到这一宫。本造来因宫落福德 → 命主大事的因在**思维 / 信念 / 习气 / 内核状态**层。

> 这是一个很特殊的命主类型 —— 其大事不由"环境推动"（迁移）、不由"婚姻引导"（夫妻）、不由"父母安排"（父母）、不由"事业牵引"（官禄）、不由"财富带动"（财帛），而是由**思想自己长出来** —— 是**纯粹的内驱型命主**。 [三合 + 四化派的"来因宫"理论]

#### §2.5.3 福德宫无主星 + 借紫贪
- **无主星**：福德宫本宫无任何 14 主星坐镇 → 该宫"主体能量空" → 命主"自我层面的主导能量"在福德宫不强
- **借对宫紫微 + 贪狼入福德**：紫贪从财帛宫（酉）借入福德宫（卯）—— 命主的"思维 / 信念"借取财帛宫的"统帅气场 + 多元欲望"

> 福德宫借紫贪的结果：命主的思维表面上有"统帅气场 + 多元欲望"（看似有想法），但因为是**借**而非**有**，所以这种"想法"**不稳定** —— 没有真正属于自己的主星根基。 [三合]

#### §2.5.4 右弼陷 + 地空
- **右弼[陷]**：陷地右弼是"辅佐力极弱"——本应辅佐自我的力量在福德宫坐陷地 → **思维上无强辅佐 / 易孤思**
- **地空[平]**：地空主"虚化 / 思想出尘 / 但不实落" —— 平地的地空是"思想容易飘空"

> 福德宫**右弼陷 + 地空 + 借紫贪 + 无小星**的组合：**思维根基偏空 + 借势 + 易飘** —— 这是一个**"看似有想法但本根飘"**的福德结构。 [三合]

#### §2.5.5 来因 + 福德的合一
- 来因落福德 → 大事之因在思想
- 福德空 + 借紫贪 → 思想本根空、借势

> 这两者叠加 → 命主"大事的根源"在一个**本来就飘**的思想结构里 —— 意味着：
> 1. 命主一生的大事**会"想到了就去做"** —— 内驱型很强
> 2. 但因为思想本根空 → 这些"想到了"的事**容易反复**（因为根基不稳）
> 3. 借紫贪的"统帅气场" → 命主想做的事会**带着统帅气** —— 但又因紫贪是借非有 → 这些事**容易半途变向**

#### §2.5.6 福德宫四化叠加（第三层重复）
福德宫宫干辛与命宫宫干辛、生年辛**三同字**（这在十二宫中只有命宫 + 来因宫合一时才出现）→ 巨门禄、太阳权、文曲科、文昌忌四化的飞入路径**三层叠加**：

- 巨门禄入子女宫：**三层叠加** → 命主先天能量 + 命宫主动 + 福德起心动念三处都指向子女宫的"长期投入大事" → 是命盘中**最强的吉端能量集中点**
- 太阳权入交友宫：三层叠加 → 朋友圈是命主权能的**最强外显场**
- 文曲科入兄弟宫：三层叠加 → 兄弟 / 朋友圈中的"才华 / 名声"是命主**最稳的口碑生成场**
- 文昌忌入父母宫：三层叠加 → 学业 / 师承 / 父母层是命主**最严重的结构性忌**

> 三层叠加在好处与坏处上的同时强化是辛年生人 + 命宫坐六阴宫（丑卯巳未酉亥）+ 来因落福德 / 命宫的特殊命主类型才有的现象 —— 命主的命运结构因此**"亮处更亮、暗处更暗"** —— 不是"中庸"型，而是**"两极对比"**型。 [四化]

### §2.6 命宫（行动力）与福德宫（思维源）的对照（核心格局之六）

本节是 §2.1 + §2.5 的合并解读 —— 是本造命盘中**最重要的内在张力结构**。

#### §2.6.1 命宫的"行强"
- 命宫廉杀 → 杀气重 + 决断 + 独立
- 七杀庙 → 将权之星
- 命宫无辅星 → 自我承担
- 命宫四化与生年四化同字叠加 → 行动方向极清晰

> 命主表层 = **行动力极强 + 杀气重 + 一旦决断便行**

#### §2.6.2 福德宫的"思飘"
- 福德宫无主星 → 思想本根空
- 借紫贪 → 思想借势
- 右弼陷 + 地空 → 辅力弱 + 易飘
- 福德宫四化与命宫 + 生年三层叠加 → 起心动念极频繁

> 命主深层 = **思想根基偏空 + 借势 + 起心动念多**

#### §2.6.3 张力的命理含义
**行强 + 思飘** 的合一 → 命主的命理结构是：
- **想到的事就做** —— 因为命宫行强（七杀决断）
- **但想到的事是从飘的根基里长出来的** —— 因为福德空借
- **结果**：命主一生**做事多 + 决断快 + 但容易事后反思"为什么当时这么做"** → 是**"行动型反思者"**而非"反思型行动者"

> 这种结构既有"机敏决断"的优势，也有"反复审视"的疲倦感 —— **命主在 25-34 岁的当前大限（夫妻宫，第3大限）正是"反复审视已做事"的结构密集期**。 [三合 + 四化 + 飞星]

#### §2.6.4 与八字盘戊戌魁罡日柱的"同向旁证"
> **仅作旁证，不修改八字结论**：
> 八字盘戊戌魁罡日柱配合伤官当令（月支酉）+ 命宫廉杀坐丑（杀气重）—— 两套盘都指向"内核刚健 + 决断 + 但内省深"的同一类型命主 —— 紫微的"行强 + 思飘"与八字的"魁罡 + 印星虚透"在不同语言下指向同一气质特征。

### §2.7 主辅四化网络的拓扑速览（核心格局之七）

本造命盘的能量网络由以下节点构成：

#### §2.7.1 节点统计
