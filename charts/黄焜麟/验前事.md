## 2. 验前事推断（逐年）

按"结构性显著度"从候选中优选 4-8 年（极少数可至 10 年）做事件层面推断。每条按以下结构展开：

```
### N.X 【YYYY 干支】N 岁 · 一句话定性

#### 结构触发
（明确写出哪几个机制叠加，列全）

#### 命理链条
1. 原局：…
2. 大运：…
3. 流年触发：…
4. 推断方向：…

#### 推断事件
> 维度：学业 / 健康 / 感情 / 家庭 / 居住 / 财务 / 事业 / 人际 中之一或多个
> 方向：顺 / 逆 / 突变 / 持续
> 强度：轻微 / 显著 / 重大
>
> 文字描述（1-3 句话；禁用模糊词；事件描述粒度 = 类型而非具体细节）

#### 可证伪点
> 一句话写明若此年命主未发生此类事件，则本条证伪
```
