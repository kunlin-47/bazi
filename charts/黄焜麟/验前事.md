## §1 原局断事（第一层）

不依赖大运 / 流年，从命局结构直接断长期型事件。本造结构性显著的维度为 4 个，其余维度（父亲 / 兄弟姐妹 / 婚姻 / 子女 / 健康倾向）结构信号偏弱或不在 25 岁命主可校验范围内，不展开。

### §1.1 母亲

#### 命理依据

**结构层面**（来自 `file 1` + `file 2`）：

1. **正印（母亲星）虚透弱印**：月干丁正印透出，但坐月支酉本气无气；丁直接通根戌中藏丁，但戌为火墓库，火气入墓未启 → 直接通根之力受锁
2. **印源全无**：原局四柱无木明透或明藏 → 印（母）本身无生扶来源
3. **远援亦虚**：广义火印体系唯一活的远援为巳中丙（戊之偏印），但巳逢日柱旬空，且与时支申六合（合中带寅巳申三刑之半）→ 印的远援空亡 + 被合化牵走
4. **月令直接克印**：月支酉为伤官当令，伤官（酉中辛）与月干丁形成"丁辛对位、丁克辛"的天干印克伤之象，但**地支层面**酉金未受丁火克伤——母亲星所在的月柱本身处于持续被金气泄耗的环境

**断语对应**（来自 [`methodology/传统断语集.md`](../../methodology/传统断语集.md)）：

- §1.1 印星无源：印透干但生印之"父母气"（火印缺木）全无 → 印是孤水
- §1.2 印星临墓：丁直接通根戌中藏丁，但戌为火墓未启 → 印资源平时不显
- 综合：本造印星处于"形上有、力上虚、用上打折"的三层虚位

#### 推断（事件类型清单）

> 维度：母亲 / 家庭
> 方向：缺位 / 持续
> 强度：显著

候选事件类型（命主勾选实际命中）：

- **母亲长期处于较高消耗状态**（候选含义：长期工作压力 / 健康有持续性问题 / 心绪长期压抑 / 操持家庭分身乏术——具体表现形式不限，但其"长期消耗"特征应在命主早年记忆中清晰）
- **与母亲的精神连结相对节制**（候选含义：母亲性格内敛 / 不善情感外露，命主自小学会自己消化情绪、与母亲在情感表达上有距离感——非冲突型疏离，是节制型疏离）
- **母亲对命主的实际陪伴稀薄**（候选含义：母亲长期外出 / 工作繁忙 / 生病 / 异地等任一原因导致童年至少有一段时期实际陪伴显著少于同龄人）

#### 可证伪点

> 若命主在与母亲相关的维度上无任何"母亲长期消耗"或"陪伴稀薄"或"情感节制"的实质特征——即母亲在命主成长期一直健康、有充足陪伴、与命主情感连结密切——则本条推断证伪。

### §1.2 早年环境

#### 命理依据

**结构层面**（来自 `file 1` + `file 3`）：

1. **年柱气场虚浮**：年支巳为日柱旬空（戊戌属甲午旬、旬空辰巳）→ 巳虽为戊之禄位（"安身立命之位"）但落空，年柱整体气场虚浮
2. **巳藏喜用 vs 忌神的削减比 2:1**：巳藏丙（偏印 = 喜用）+ 戊（比肩 = 喜用）+ 庚（食神 = 忌神），空亡对喜用的削弱明显大于对忌神的削弱 → 早年"该有的支援"打折更多
3. **童年大运丙申（9-19 岁）补印效用打折**：丙偏印透干本是印之天然补正，但坐申被金气泄克 → 童年期"有印资源但难以充分发挥"
4. **盘面几何**：三会金锐（月日时三柱）+ 单一火点远悬年柱且空 → 命主"早年精神资源是孤悬的、被远置的"，与早年家庭情感连结的体感对应一致

**断语对应**：

- §1.1 印星无源（早年支援系统从根上就薄）
- §6.6 空亡逢冲（早年环境本身带空——巳逢日空——使早年家庭气场虚浮）

#### 推断（事件类型清单）

> 维度：早年环境 / 家庭
> 方向：不稳定 / 节制
> 强度：显著

候选事件类型：

- **早年家庭气场带"虚浮"色彩**（候选含义：早年家境有迁移 / 不稳定 / 经济或居住条件多变 / 家庭重要决策反复——具体形式不限，但"早年生活缺乏'稳稳的'安定感"应是命主可识别的体感）
- **童年期精神资源是"有但不够用"**（候选含义：父母 / 长辈 / 师长虽有但实际帮助命主成长的"密度"偏低；命主可能从小习惯"靠自己消化"而非"向人求助"）

#### 可证伪点

> 若命主早年（约 0-15 岁）家境一直安定稳固、无任何迁移或大变动、且童年期与父母 / 长辈 / 师长的精神支撑密集充足——则本条推断证伪。

### §1.3 性格驱动

#### 命理依据

**结构层面**（来自 `file 1` + `file 3`）：

1. **伤官格 + 佩印之形**：月令酉金当令、天干并透辛庚、地支申酉戌三会金 → 伤官气根之深之实使主格成立无疑；佩印之形虽具但印为虚透弱印
2. **戊戌魁罡日**：性刚果决、聪明决断；但身偏弱致魁罡之刚健效力打折，表现为"**有刚气而无刚力**"——性格底层有决断与不肯认输的硬度，但因身偏弱难以长时间维持高强度对抗
3. **华盖与火库同支**：日支戌为华盖位 + 戌中藏丁（火库未启）→ 内在精神火种与"修身 / 独处"倾向叠加
4. **核心张力**：伤官输出之锐 vs 印星调护之虚 → 才气有结构但稳定性不足；外显高效与内在紧绷并存
5. **不同于典型伤官泄秀**：日支戌为强根使其在伤官输出强势的盘面中仍能担当统筹核心而非冲撞者；课题不在收敛锋芒，而在温养火种

**断语对应**：

- §4.1 伤官泄秀（才气外显，思维敏锐）
- §4.4 伤官配印（才气有体系倾向）
- §6.1 魁罡日（性刚果决，有决断硬度但身偏弱时刚气有度无力）

#### 推断（事件类型清单）

> 维度：性格 / 自我
> 方向：持续 / 双面
> 强度：显著

候选事件类型：

- **对外锋芒 + 对内紧绷的两极特质**（候选含义：在外人 / 工作 / 学习场景中表现出敏锐、高效、有决断力，但**独处时**有显著的自我审视密度、思维反复、精神紧绷感——这种"内外两极"是过去 25 年的持续底色）
- **过去有过"高功率运转致身心耗竭"的体验**（候选含义：在某个学业高压期 / 重要项目 / 备考阶段，曾出现过"明明在硬撑但内核已经透支"的体感，可能伴随睡眠 / 情绪 / 自我怀疑的实质表现）

#### 可证伪点

> 若命主自我体感是"放松 / 散漫 / 容易满足 / 既不锋利也不内耗"，与"对外锋芒 + 对内紧绷"两极特质完全不符——则本条推断证伪。

### §1.4 重大变故倾向

#### 命理依据

**结构层面**（来自 `file 1::day_pillar_qualities` + `file 3::dayun.list` + `file 2::structure_activation_hooks`）：

1. **魁罡忌冲**：戊戌日为四魁罡之一，凡大运 / 流年带辰、丑、未触戌者为结构动摇关键节点（依宽泛派，详见 [`methodology/basics.md`](../../methodology/basics.md) §6.5）
2. **过去 25 年内的两段结构性显著时段**：
   - **2009 己丑（虚岁 9）**：大运起换年（月柱延续 → 丙申）+ 流年地支丑刑戌（魁罡日支被刑，丑戌未三刑之半）→ 第一次结构性触发节点
   - **2018 戊戌（虚岁 18）**：**日柱完全伏吟**（流年戊戌 = 日柱戊戌）+ 戊食神透干 → 自我内核被复刻强化、华盖伏吟自我审视密度抬高的关键年；同期处于丁未运后半段的高压期

**断语对应**：

- §6.1 魁罡日（一生有几个"冲魁罡 / 刑魁罡"的关键节点，丑刑戌为其一）
- §6.7 月柱伏吟（戊戌伏吟于日柱比月柱优先级更高，事件烈度更强）
- §6.6 空亡逢冲（2019 巳亥冲为后续触发，但 2018 已先行铺垫）

#### 推断（事件类型清单）

> 维度：重大变故 / 学业 / 居住
> 方向：突变 / 内核搅动
> 强度：显著（两个时段各显著一次）

候选事件类型（**两个时段分开校验**）：

- **2009 年前后（虚岁 8-10）有家庭 / 居住 / 学业层面的结构性变化**（候选含义：家庭重要决策、迁居、转学、家庭成员状态变化等任一项；这一年是命主"被结构性事件强制经历的第一个成长拐点"，可能命主已记忆模糊但向父母核对应能确认）
- **2018 年前后（虚岁 17-19）有学业极高压期 + 显著的内核搅动**（候选含义：高考 / 大学方向选择 / 高强度备考的压力期，同期伴随明显的自我审视加深 / 与原有人际圈疏离感 / 与"家"维度的情绪摩擦——这一年是命主前 25 年里**最显著**的一次结构性叠加，命主应有清晰记忆）

#### 可证伪点

> 若 2009 年前后命主家庭 / 居住 / 学业全无任何实质变化，**且** 2018 年前后命主未处于学业极高压期、亦无任何内核搅动 / 自我审视加深的体感——则本条推断证伪。
> （两个时段是 OR 关系：只要其中一个时段命中，本条整体不算证伪）
