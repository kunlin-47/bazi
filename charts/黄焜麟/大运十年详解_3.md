### ◇ 第七步 · 庚寅（68-78 岁）★ —— 晚运双刃高峰（不是用神最完整）

> 副标题：戊长生位 · 寅中丙印长生（中气）· 寅本气甲七杀 · 寅巳申三刑全启 · 庚食神透干

#### 一句话总诀

晚运的关键大动期——长生位有利但三刑全启很折腾，需要"扛得住、守得稳"的十年。

#### 这十年是什么意思

**对应人生阶段**：68-78 岁。

**命运给的卡片**：长生有利 + 三刑大动 + 食神透增金的**双刃局面**。

**为什么不是"用神最完整"**：

很多人会被"戊在寅长生 + 寅中丙印长生"误导以为是大吉。但要看清楚：

- 寅的**本气是甲七杀**（克我），丙印只是**中气**（次于本气）
- 戊在寅是**长生位**（不是最旺地），不如午是**帝旺地**那样直接
- 天干**庚是食神（金气，对你是忌神）**——这是金气透出加压
- **寅巳申三刑全启**——精神核心+印根+食神同时被搅动，是大动期不是平稳期
- **寅申冲**——时柱（驿马、文昌、子女宫）被冲

所以这十年是**长生位补给 + 三刑全启大动 + 金气增压**的双刃局面，**真正的"用神最完整"是 28-38 岁的甲午运**。


**现实表现**：

- 退休前后的人生第二阶段
- 戊长生位 → 你会感觉"如新生"，有重新开始的能量
- 寅中丙偏印 → 内在精神支撑得到补给（虽然只是中气级）
- 但寅巳申三刑全启 → 健康/家庭/关系层面可能有结构性变动
- 庚食神透干 → 金气再增，输出系统被推得更猛
- 寅申冲 → 时柱（晚段、子女宫）大动

**关键体感**：长生位的"如新生"感 vs 三刑全启的"被刑动"感 → 这十年是**两极并存**的体验。

**关键提醒**：

1. **2070 庚寅年 = 第二次岁运并临**（双倍能量）。能量峰是**双倍食神 + 双倍七杀根 + 三刑双倍** → 这是**压力峰**而不是补给峰，须特别留意（具体待流年分析时细推）
2. **2074 流年甲午 → 寅午戌三合火局完成**——这是十年中最大的结构性吉性事件
3. **守住前一步运（辛卯）累积的内在精神资源**，不被三刑动牵走方向
4. 健康层面：三刑全启的年代须留意身心起伏（具体以医生建议为准）

#### 命理依据

- **主导能量（关键三件事）**：
  1. **寅巳申三刑全启**——原局已有巳、申，运支至寅 → 三刑成立 → 大动期（结构性大事件）
  2. **戊长生于寅 + 寅中丙偏印长生（中气级补给）**——双重长生位补给（吉，但非最强）
  3. **庚食神透干 + 寅申冲**——金气增 + 时柱被冲（双重忌端）
- **寅藏干十神精确分布**：
  - 本气甲（七杀，克我）—— 寅这个支对戊的本气是**压力**
  - 中气丙（偏印，用神）—— 印星补给，但次于本气
  - 余气戊（比肩，自气）—— 比肩根
- **戊长生在寅 vs 戊帝旺在午**：长生 < 帝旺；庚寅之"长生级补给"不及甲午之"帝旺级补给"
- **寅中丙印（中气）vs 午中丁印（本气）**：中气 < 本气；丙偏印（同性，刚）vs 丁正印（异性，柔）—— 丁更适合戊作为"温养"型的印
- **2070 岁运并临是压力峰不是补给峰**：流年=大运=庚寅 → 双倍庚食神（双倍金气）+ 双倍寅本气甲七杀 + 三刑双倍
- **整体判断**：★ **晚运双刃高峰**——长生有补给、印有中气、但三刑全启 + 金气增 + 七杀本气克身 → 关键在流年配合（火土流年吉，金水流年凶）

### ◇ 第八步 · 己丑（78-88 岁）—— 晚年回落、守住已得的十年

> 副标题：巳酉丑三合金完成 · 丑戌相刑 · 印根被夺

#### 一句话总诀

金气至顶、原来的火印被合走——晚年的"守"期，不再追新。

#### 这十年是什么意思

**对应人生阶段**：78-88 岁。

**命运给的卡片**：金气至顶 + 旧成就开始消耗。

**现实表现**：

- 身体精力下降（自然规律）
- 金气再聚 → 财气重但反而压身（你不再需要更多金气）
- 戌火库再被刑动 → 前一步寅运累积的"火气"开始散
- 巳被合走化金 → 你最远的印根（巳本气丙）被夺走

**关键体感**：上一步寅运是"两极并存"，这一步丑运是"落叶归根"。

**关键策略**：

- **守住前一步寅运得到的，不再追新成就**
- 不要被晚年才出现的"机会"诱惑（庚辛流年遇到的"看似贵人"很可能是耗印型）
- 保养身体、整理过去、传承（具体健康以医生为先）

**生活意义**：

- 一生该完成的在 28-38 岁立家立业、68-78 岁两极高峰中已完成
- 78 岁之后是"安然"——把过去几十年的成果整理传承

#### 命理依据

- **主导能量**：巳酉丑三合金局完成 + 丑戌相刑——金气至顶、巳火印根被合走、戌火库再刑动
- **巳酉丑三合金完成**：原局已有巳、酉，运支至丑 → 三合金完成 → 金气贯穿底盘 + 月柱 + 运支 → 金气至顶
- **巳被合走化金**：年支巳本是火源（藏丙），三合后巳被合化金 → ★ **印根（巳本气丙）被夺**
- **丑戌相刑（库刑）**：运支丑 vs 日支戌 → 两土相刑 → 戌火库被刑动（这次是负面搅动）
- **丑湿土晦火生金**：丑作为湿土，比燥土（戌、未）更生金 → 进一步加重金气
- **己劫财透干**：扶身一线，但与年时之金共存，作用有限
- **整体判断**：★ **晚年风险期**——金气至顶 + 火印被夺 + 火库再刑 → 必须"守"，不能"再追"

## 7. 岁运并临年标记

> **岁运并临** = 流年柱与大运柱**完全相同**——能量峰值。你一生有**两次**：

| 序 | 公历 | 实岁 | 干支 | 大运 | 方向 | 状态 |
|---|------|------|------|------|------|------|
| 1 | 2016 | 14 | 丙申年 | 丙申运 | 双刃（丙偏印 + 申食神） | **已过**，可作回溯印证 |
| 2 | 2070 | 68 | 庚寅年 | 庚寅运 | **★ 压力峰**（双倍食神 + 双倍七杀根 + 三刑双倍） | **待发**，最高优先级动态观察点 |

### 7.1 关于 2070 的关键澄清

很多人会以为"庚寅年×庚寅运岁运并临是吉年"——这是**错误判断**。机制上：

- 大运庚（食神，忌神）+ 流年庚（食神，忌神）= 双倍金气加压
- 大运寅本气甲（七杀，克身）+ 流年寅本气甲 = 双倍七杀压身
- 寅巳申三刑被流年寅再次激活 = 三刑双倍触发

所以 2070 岁运并临是 **能量峰** + **压力峰**，**不是补给峰**。具体细推待流年分析时单独展开。

### 7.2 关于"马倒禄斜虚岁年龄"的澄清

排盘软件原文除上述两个岁运并临年外，还另列"马倒禄斜虚岁年龄：13、19、43、49、73"——这是**口诀类年龄**（机制不透明），与"岁运并临"是**不同的两件事**，本仓库不予采用。详见 `八字静态分析_1.json` 的 `_meta.stance_on_software_outputs.马倒禄斜虚岁列表`。
