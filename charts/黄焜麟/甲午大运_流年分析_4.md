## §3 整段过渡年简写

> **本运段无过渡年**。

甲午运 10 个流年的档次分布：

| ★★（极高能量年）| ★（高能量年）| 过渡年 |
|---|---|---|
| 4 个（2032 / 2034 / 2036 / 2038 / 2039 共 5 个，但 2039 与 2034 / 2036 / 2038 并列峰位则 5 个 ★★ ） | 5 个（2030 / 2031 / 2033 / 2035 / 2037）| 0 个 |

精确清单（含已修正后的档次判定）：

- **★★ 极高能量年（5 个）**：2032 壬子（冲运支帝旺）、2034 甲寅（寅午戌三合火完成 + 三刑全启第二次）、2036 丙辰（辰戌冲第二次 + 用神丙再透 + 得子年候选）、2038 戊午（戊帝旺位 + 戊羊刃位双层激活 + 一生独有事件）、2039 己未（巳午未三会火完成 + 大运起换 + 子女星机制闭环）
- **★ 高能量年（5 个）**：2030 庚戌（戌火库双重激活 + 妻宫复刻）、2031 辛亥（巳亥冲第二次 + 子女星双层被克）、2033 癸丑（巳酉丑三合金第二次 + 戊癸合化火 + 魁罡被刑第三次）、2035 乙卯（卯酉冲再激 + 子女星机制三段式）、2037 丁巳（巳填日空再次 + 印星双层透出）

> **0 过渡年**与 [`prompts/prompt_流年分析.md`](../../prompts/prompt_流年分析.md) §5.3 中"★★ 大运 5-6 个高能量年 + 4-5 个过渡年"的预期对照，甲午运的高能量年密度**远超预期**——10 年全为高能量年，且其中 5 个达到 ★★ 级别。这本身是命主甲午运结构性钩子触发密度极高的反映：原局已有的"巳-酉-戌-申"四支与运干甲、运支午的合冲刑会几乎全覆盖；加上甲午运恒在的"用神火气基底 + 杀印相生流通 + 印帝旺地 + 立家立业窗口"四重叠加，使得**甲午运几乎"无平年可言"**。

> 这与乙未运的"10 高能量年 + 1 过渡年"形成对比——乙未运的"摇晃感"使每年都有触发但偶有沉淀年；甲午运的"补强感"使每年都被结构性事件填满。**事件密度 + 事件性质**两个维度看，甲午运是命主一生中能量浓度最高的 10 年。

#### §5.4.2 对偶的核心意义（重申 + 深化）

1. **乙未运的"摇晃 + 内耗 + 形式补给"为主的过渡期 ——> 甲午运的"实质补给 + 立家立业 + 实位落定"的高峰期**

2. **命主回看时会发现：乙未运的每个结构性事件都在甲午运找到了"加重版" / "实质化版本"**——这是"一生最大补强期"的真正含义：
   - 子女星在乙未运首透即被合走（2024 甲七杀首透 + 2025 乙正官透即被双层合化金）—— 在甲午运结构性运干持续在位（甲为运干 10 年）+ 2034 甲伏吟运干达顶 + 2036 辰中乙正官入命 + 2039 甲己合化土完整闭环
   - 妻星在乙未运首透即被合走（2022 壬偏财首透 + 2023 癸正财首透 + 2024 / 2025 暗动）—— 在甲午运 2032 壬偏财明位再透（婚配实质性大事件）+ 2033 癸正财再透（落定承接）+ 2036 辰中癸正财入命（得子年候选）

### §6.1 边界声明

按 [`prompts/prompt_流年分析.md`](../../prompts/prompt_流年分析.md) §1.5 / §10.5，本四件套**不做**：

- ❌ **不下沉到月 / 日 / 时级**：流年内某月某日某时的吉凶不属本任务（如有需要属"流月分析" / "择日"等独立任务）
- ❌ **不写行动指引**：按 [`prompts/prompt_大运十年详解.md`](../../prompts/prompt_大运十年详解.md) §三的边界，"该做什么 / 不该做什么"留在大运层；本任务**只**回答"这一年结构上会发生什么类型的事"，不回答"这一年应该怎么做"
- ❌ **不出助运推荐**:颜色 / 数字 / 方位 / 饮食 / 时辰 / 贵人方位等不做
- ❌ **不引入紫微 / 奇门 / 风水**:只做子平八字
- ❌ **不重新做大运层判断**:大运的整体性质、用神方向已由 [`大运十年详解_2.md`](./大运十年详解_2.md) 给出，本任务在其底盘上展开
- ❌ **不重新做原局断事**:与验前事相关的"长期型事件"(家庭、性格、健康倾向)不在本任务范畴

本任务采用"按时间段切分 + 综合视图独立"的产出策略：

> **拆分依据**：单文件流年分析的体量约 700-1200 行（按 [`prompts/prompt_流年分析.md`](../../prompts/prompt_流年分析.md) §七），命主甲午运结构性钩子触发密度极高（**0 过渡年 + 5 ★★ 极高能量年 + 5 ★ 高能量年**），单文件容易超限；按时间段切分使每份文件控制在 200-400 行，便于阅读与定位。
