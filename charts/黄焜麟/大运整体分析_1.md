### ◇ 第一步 · 丙申（8-18 岁）—— 童年金水塑造的底色期

> 副标题：偏印虚透 · 申申伏吟 · 三会金气加深

#### 一句话总诀

童年被外部塑造的十年，重点不在这步。

#### 这十年是什么意思

**对应人生阶段**：从学龄前到高中。

**命运给的卡片**：被环境塑造。

**现实表现**：

- 父母、学校、老师的"规则结构"在你身上深度定型
- 童年外部环境多金水气场（按你的命局判断属偏忌方向），可能反映为：早年家庭氛围理性化、规则感强、压力较大
- 你的"思维早熟、动手早、表达欲强"在这十年开始显现（伤食食神的早期显化）

**关键体感**：外面看聪明灵动，里面感是"敏感与紧绷"的底色养成。

**关键提醒**：对成年后的你来说，这一步是**"理解你为什么是现在这样"** 的背景资料，不是行动指南。可参考的是 **2016 年（实岁 14）岁运并临的双倍能量年**——那年的体验可作为命主自我校验"命局推断与实际经历是否对应"的回溯参照点。


#### 命理依据

- **主导能量**：申申伏吟（运支=时支）+ 月酉日戌时申再加运申 → 整盘金气连续不断 → 伤食最旺，泄身耗印最深
- **丙偏印虚透**：丙偏印透干本应是吉，但**坐申为病地 + 申中壬水暗克丙** → 印来虚补、效用打折
- **申为年柱旬空之一，运至填实**：年空被填实（次效），轻微补强结构感但不动主线
- **整体判断**：**忌方向偏重 + 印来虚补**——童年金水气场塑造的定型期

### ◇ 第二步 · 乙未（18-28 岁，**当前进行中**★）—— 身份初建但内核摇晃的十年

> 副标题：戌未刑 · 乙庚合化金 · 子女星首透即被合

#### 一句话总诀

外面在拼搏、里面在摇晃，攒印底为下一步做准备。

#### 这十年是什么意思

**对应人生阶段**：大学到 28 岁工作初期。

**命运给的卡片**：身份感来 + 内核被搅动。

**现实表现**：

- 第一次有"社会身份"（乙正官透干）→ 学业、职业身份的建立期
- 但这个身份不稳（乙坐未燥土 + 乙庚合走 + 辛克乙）→ 容易在"想做什么"和"实际做什么"之间反复
- **戌未刑** → 内心的"根"被搅动，常感"我是谁"、"我要去哪"的疑问

**关键体感**：

- 外面看：学业有成、初入职场、表面有方向
- 里面感：内核不稳、容易自我怀疑、夜深尤甚


**关键提醒**：

1. **不要把"动荡感"误判为"人生不顺"**——这是结构性的（戌未刑+乙庚合走），下一步运（甲午）就完全不同
2. **这十年最该做的**：积累印的底子——读书、思考、师承、建立内在体系——为甲午运的"印星正补"准备好接受能力
3. **不要急着结婚生子**——妻宫被刑动 + 子女星被合走，重大家庭决定**留到下一步甲午（28 岁起）才落定为佳**
4. 25 岁的当下：你能感受到的"内心摇晃感"是结构性的、不是错觉

#### 命理依据

- **主导能量**：戌未刑 + 乙庚合化金——日支被刑（妻宫+比肩主根+火墓库三重身份的戌被搅动），子女星首透即被合走
- **乙正官透干**：原局子女星甲乙完全无木的状态被首次打破，但乙坐未燥土 + 年干辛克乙 → 子女星象征虚透
- **乙庚合化金**：运干乙 vs 时干庚 → 异性合化为金 → 子女星之力被食神合走分流
- **未中藏丁印（虚根）**：本应是火印加根，但**丁火生己土，未中丁被己泄气** → 印加根的实效打折
- **整体判断**：**双刃偏负 + 内核搅动型**——身份初建但内核摇晃，是过渡期不是落定期
