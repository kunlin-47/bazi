### ◇ 第一步 · 丙申（8-18 岁）—— 童年金水塑造的底色期

> 副标题：偏印虚透 · 申申伏吟 · 三会金气加深

#### 一句话总诀

童年被外部塑造的十年，重点不在这步。

#### 这十年是什么意思

**对应人生阶段**：从学龄前到高中。

**命运给的卡片**：被环境塑造。

**现实表现**：

- 父母、学校、老师的"规则结构"在你身上深度定型
- 童年外部环境以**金气为主导**（申为金主气，月酉日戌时申再加运申，五重金气堆叠；金对戊土是食伤，属偏忌方向），可能反映为：早年家庭氛围理性化、规则感强、压力较大
- 你的"思维早熟、动手早、表达欲强"在这十年开始显现（伤食食神的早期显化）

**关键体感**：外面看聪明灵动，里面感是"敏感与紧绷"的底色养成。

**关键提醒**：

1. 对成年后的你来说，这一步是**"理解你为什么是现在这样"** 的背景资料，不是行动指南
2. **2016 年（实岁 14）是岁运并临年**：大运丙申 + 流年丙申 → **双倍丙偏印透 + 申申申申四重伏吟堆叠（月酉 + 日戌 + 时申 + 流申 + 运申）+ 童年金气堆叠最厚的一年**。命主回看这一年的具体体感（身体 / 学业 / 家庭氛围）可作为"命局推断与实际经历是否对应"的回溯参照点
3. **此十年留下的性格印记**：对秩序的内化、对效率的追求、对失控的不适——这些是丙申运塑造的"底层操作系统"，进入后续大运后仍会持续运行
4. **与父母关系的早期定型**：印星虚补的童年期（丙偏印虚透）→ 与父母的连结象偏向"理性 / 规则感强"而非"温情滋养"——这一时段的"被滋养"体感打折，是日后"难深度放松"性格特征的早期雏形


#### 命理依据

- **主导能量**：申申伏吟（运支=时支）+ 月酉日戌时申再加运申 → 整盘金气连续不断 → 伤食最旺，泄身耗印最深
- **丙偏印虚透**：丙偏印透干本应是吉，但**坐申为病地 + 申中壬水暗克丙** → 印来虚补、效用打折
- **申既是时支也是年柱空亡支（次效）**：丙申运至 → 与时支申伏吟 + 加强空亡支的填实，形成"申位双重激活"
- **巳火印主体仍在日空状态**：童年大运无任何支来填巳空（辰巳为日空，丙申运中无辰无巳）→ 原局唯一活的火印远援（巳中丙）整个童年期保持遮蔽 → 对应"内在火气尚未启动"的童年体感
- **整体判断**：**忌方向偏重 + 印来虚补 + 主火印仍闭**——童年金气塑造的定型期，内在火种尚未醒来

### ◇ 第二步 · 乙未（18-28 岁，**当前进行中**★）—— 身份初建但内核摇晃的十年

> 副标题：戌未刑 · 乙庚合化金 · 子女星首透即被合

#### 一句话总诀

外面在拼搏、里面在摇晃，攒印底为下一步做准备。

#### 这十年是什么意思

**对应人生阶段**：大学到 28 岁工作初期。

**命运给的卡片**：身份感来 + 内核被搅动。

**现实表现**：

- 第一次有"社会身份"（乙正官透干）→ 学业、职业身份的建立期
- 但这个身份不稳（乙坐未燥土 + 乙庚合走 + 辛克乙）→ 容易在"想做什么"和"实际做什么"之间反复
- **戌未刑** → 内心的"根"被搅动，常感"我是谁"、"我要去哪"的疑问

**关键体感**：

- 外面看：学业有成、初入职场、表面有方向
- 里面感：内核不稳、容易自我怀疑、夜深尤甚


**关键提醒**：

1. **不要把"动荡感"误判为"人生不顺"**——这是结构性的（戌未刑 + 乙庚合走），下一步运（甲午）就完全不同
2. **这十年最该做的**：积累印的底子——读书、思考、师承、建立内在体系——为甲午运的"印星正补"准备好接受能力
3. **重大家庭决定（婚配 / 生育）倾向于推迟到甲午运再落定**——本步妻宫被戌未刑动 + 子女星乙透即被合走，即便此步成婚结局未必稳；若已遇可托付的人，建议**婚成而生育推后**到甲午运（2029 起）再考虑
4. 25 岁的当下：你能感受到的"内心摇晃感"是结构性的、不是错觉

#### 命理依据

- **主导能量**：戌未刑 + 乙庚合化金——日支被刑（妻宫+比肩主根+火墓库三重身份的戌被搅动），子女星首透即被合走
- **乙正官透干**：原局子女星甲乙完全无木的状态被首次打破，但乙坐未燥土 + 年干辛克乙 → 子女星象征虚透
- **乙庚合化金**：运干乙 vs 时干庚 → 异性合化为金 → 子女星之力被食神合走分流
- **未中藏丁印为中气，藏干位置力本就薄**：未的本气是己土比劫，这一支的主导效应是"助身比助"而非"增印根"——所以未中丁作为火印加根，虽形式上有，实质支撑很有限（参考 [`methodology/basics.md` §三.4 藏干内部不互相生克](../../methodology/basics.md#三五行的现实含义以戊土日主为例)）
- **整体判断**：**双刃偏负 + 内核搅动型**——身份初建但内核摇晃，是过渡期不是落定期
