# bazi —— 八字推演框架

子平八字推演的通用框架：从专业排盘软件原始输出出发，经过 AI 化处理生成结构化静态分析文件，再做大运 / 流年等动态推演。当前已分析一位命主，框架本身按"通用方法论 + 多命主目录"组织，可扩展。

**只做八字解盘**——排盘由专业软件完成，本仓库不做排盘。紫微斗数命盘资料若有则隔离在命主目录的 `ziwei/` 下，**不参与**八字推演。

## 处理链路

```
charts/<命主>/南方排八字专业程序.txt （原始软件输出，含黑箱与不合理项）
        ↓ 按 prompts/static_extraction.md 处理
charts/<命主>/八字静态分析_{1,2,3}.json （AI 易读的结构化基准）
        ↓ 按 prompts/dayun_overview.md 处理
charts/<命主>/大运整体分析_{1,2,3}.md （八步大运总览，不下沉流年）
```

## 三层职责

| 层 | 内容 | 路径 | 变动频率 |
|---|---|---|---|
| 知识层 | 通用八字命理知识与处理规范（跨命主复用） | `methodology/` | 演进式修订 |
| 指令层 | 自包含的 AI 解盘任务指令 | `prompts/` | 跟随任务定义演进 |
| 命主层 | 单一命主的原始排盘 + 静态分析 + 动态产出 | `charts/<命主>/` | 跑测时更新 |

**约束**：通用层（methodology / prompts）不允许写入命主特定结论。命主特定的发现先沉淀在该命主目录，多命主验证有普适性后才升级为通用规则。

## 目录结构

```
bazi/
├── README.md                            # 本文件 · 仓库总说明
├── methodology/                         # 知识层（跨命主复用）
│   ├── README.md
│   ├── basics.md                        # 概念语义
│   ├── lookup_tables.md                 # 硬数据查表
│   └── raw_paipan_processing.md         # 原始排盘 → 静态分析的方法论
├── prompts/                             # 指令层
│   ├── README.md
│   ├── static_extraction.md             # 原始排盘 → 静态分析 JSON
│   └── dayun_overview.md                # 大运整体分析（不下沉流年）
├── charts/                              # 命主层（按命主隔离）
│   └── 黄焜麟/                           # 一个命主一个目录
│       ├── README.md                    # 命主入口（基本信息 + 核心判断）
│       ├── 南方排八字专业程序.txt          # 原始软件输出 · GB18030 · 冻结快照
│       ├── 八字静态分析_{1,2,3}.json      # AI 化静态基准
│       ├── 大运整体分析_{1,2,3}.md        # 八步大运总览
│       └── ziwei/                       # 紫微斗数（隔离，不参与八字）
└── .kiro/steering/workflow.md           # 协作工作流偏好
```

> **关于 `南方排八字专业程序.txt`**：GB18030 编码的**证据快照**，**冻结不动**。AI 不直接消费此文件，所有 AI 化分析以 `八字静态分析_{1,2,3}.json` 为唯一入口。txt 仅在需要回溯"软件原本说了什么、我们为什么剔除某段"时作为旁证查阅；剔除决策在 `八字静态分析_1.json._meta.stance_on_software_outputs` 中显式记录。

## 当前阶段范围

以下内容**当前阶段不做**，等核心链路稳定后逐步补入：

- 助运体系（数字 / 颜色 / 方位 / 贵人方位 / 材质 / 饮食 / 时辰）
- 发展地点推荐（城市 / 国家 / 居所朝向）
- 流年级聚焦（每步大运下沉到逐年）
- 已发生事件校验（命中度对照）
- 三元九运专题

集中声明在此处，下游文档不再各自重复"暂不做"清单。未来开始做某项时，新增对应的 `methodology/<topic>.md` + `prompts/<topic>.md` + 命主目录产出，并从本节移除该项。

## 命名约定

- 通用层（`methodology/`、`prompts/`）用英文命名
- 命主目录用命主代号或假名（中文），命主层产出文件用中文命名（如 `八字静态分析_*.json`、`大运整体分析_*.md`）
- 命主目录隔离原则：每个命主一个 `charts/<名>/` 目录，跨命主不共享文件名前缀
