# 传统断语集

> 收录命理学中**机制清晰、可循推演**的传统断语，按十神类别组织，每条标"适用维度"标签便于按事件维度反查。
>
> **本文是知识库**——按需查询的字典，而非任务的执行规则。具体怎么用见相关任务方法论：
> - 验前事任务：`methodology/验前事方法论.md` §二.5
> - 大运 / 流年分析任务：未来扩展
>
> **范围**：当前为最小可用集（30 条），覆盖 9 个事件维度的核心断语。后续按命主跑测中遇到的"未覆盖"情况增量补。
>
> **边界**：只收录**机制清晰可循**的断语——可从十神 + 地支 + 长生十二宫等结构机制推出。
> 剔除红鸾、孤辰、寡宿、丧门、吊客、披麻、白虎、童子煞等纯口诀类
> （与 `raw_paipan_processing.md` §三神煞过滤原则一致）。

---

## 字段约定

每条断语含 6 个字段：

| 字段 | 含义 |
|---|---|
| **机制** | 底层命理结构机制（结构性语言，不用口诀）|
| **结构条件** | 什么命局结构下断语成立 |
| **适用维度** | 9 维度框架中的一个或多个：父亲 / 母亲 / 兄弟姐妹 / 婚姻 / 子女 / 健康倾向 / 早年环境 / 性格驱动 / 重大变故 |
| **推断方向** | 可推出的事件类型清单（多候选并列，避免单一具体事件）|
| **限制** | 什么情况下断语不成立或反向（避免误用）|
| **交叉引用** | 相关 lookup_tables / basics 章节 |

## 一、印星类断语

印星（正印 / 偏印）= 生我者 = 母亲 / 学习 / 精神支撑 / 长辈型贵人。

### 1.1 印星无源

- **机制**：印星天干透出但原局缺生印之"父母气"（如火印缺木、水印缺金、金印缺土）→ 印无源头，是孤水
- **结构条件**：印星透干 + 原局四柱（含藏干）无生印之五行
- **适用维度**：母亲 / 早年环境 / 学习 / 精神支撑
- **推断方向**：与母维度某种实质挑战（健康 / 性格 / 缺位 / 分身乏术 之一或多个）/ 学业靠自己硬撑 / 精神支撑系统不稳
- **限制**：若大运补印源（如木运补火印）则缓解；身旺不需印则不构成"无源"问题
- **交叉引用**：lookup_tables.md §三 五行生克

### 1.2 印星临墓

- **机制**：印星藏于墓库（如丁印藏戌中、丙印藏戌中、辛印藏丑中）→ 印气入墓未启
- **结构条件**：印星仅以"墓中藏干"形式存在，无明透 / 无开库
- **适用维度**：母亲 / 早年环境 / 学习 / 精神支撑
- **推断方向**：印资源平时不显（与母情感节制 / 学问深沉但表达少）/ 须冲合开库方启用
- **限制**：墓被冲合则启动，转为"印有用"；身弱无印则可能加重身弱
- **交叉引用**：basics.md §四.1 库冲与库合 / lookup_tables.md §二 地支藏干

### 1.3 印星受冲（动印）

- **机制**：印星所在地支被冲 → 印根动摇 → 母运 / 学业 / 精神支撑系统的实质性变动
- **结构条件**：印星本根（含藏干层面的根）所在支被流年 / 大运的对宫支冲
- **适用维度**：母亲 / 早年环境 / 学习 / 精神支撑 / 重大变故
- **推断方向**：母亲健康 / 与母的情感转折 / 学业中断或转向 / 精神资源震荡
- **限制**：印过旺时被冲反而是"减负"，可能转吉；身弱用印时被冲加重不利
- **交叉引用**：lookup_tables.md §八 地支六冲 / basics.md §四 合冲刑害伏吟

### 1.4 枭神夺食

- **机制**：偏印（枭）克食神。食神为日主温和输出 / 女命子女星，偏印为非主流学问 / 母性强势之印；偏印强而食神弱时，食神被夺去自然发挥空间
- **结构条件**：偏印透干 + 食神坐弱地（坐绝、坐墓、被冲合）
- **适用维度**：母亲 / 子女（女命）/ 表达创作 / 性格驱动
- **推断方向**：母亲管控较严或与母关系紧张但难离 / 创造力被压制 / 女命子女缘晚或难
- **限制**：身弱用印时偏印为生身正用，"夺食"反为正面；身旺食神有力时"夺"不构成
- **交叉引用**：lookup_tables.md §五 十神矩阵 / basics.md §二 十神

### 1.5 印重身轻

- **机制**：印星过旺 + 日主弱（看似生身但实则被印压）→ 母强而子弱
- **结构条件**：天干印透 + 地支印根多 + 日主自身根浅
- **适用维度**：母亲 / 性格驱动 / 早年环境
- **推断方向**：母亲影响力极大（性格强势 / 主导日常）/ 命主依赖性强 / 自我决断力弱
- **限制**：身旺时印重为正用；命局有食伤泄印 + 财星制印则可化解
- **交叉引用**:basics.md §五 用神 / 喜神 / 忌神

## 二、财星类断语

财星（正财 / 偏财）= 我克者 = 物质资源 / 妻星（男）/ 父亲（男女命同看偏财）。

### 2.1 财来破印

- **机制**：财克印 → 财旺则印被克 → 学业 / 母运被物质牵扯
- **结构条件**：财星透干并旺 + 印星虚弱（虚透 / 无根 / 受冲）
- **适用维度**：母亲 / 学习 / 早年环境 / 婚姻（间接）
- **推断方向**：早年因家境物质问题影响学业 / 母亲与父亲关系失衡 / 求学路上有经济压力
- **限制**：印旺财弱时不构成；财印俱旺且通关时为"财印两全"反吉
- **交叉引用**：basics.md §六.3 配印 / 配杀 / 配比

### 2.2 财星临墓

- **机制**：财星藏于墓库（壬财藏辰、丙财藏戌等）→ 财气入墓
- **结构条件**：财星仅以"墓中藏干"形式存在
- **适用维度**：父亲 / 婚姻（男命）/ 财运
- **推断方向**：财积难散（节俭性格）/ 父亲健康挑战或与父缘节制 / 男命妻子内敛或与妻聚少
- **限制**：墓被冲合则财库被打开，转为"财库俱开"；财星本身已旺时入墓为存财
- **交叉引用**：basics.md §四.1 库冲与库合

### 2.3 比劫夺财

- **机制**：比劫克正财 / 偏财 → 兄弟分财 / 配偶受夺（男命）
- **结构条件**：原局比劫多于一处 + 财星弱（无根 / 受空 / 被冲）
- **适用维度**：兄弟姐妹 / 婚姻（男命）/ 父亲 / 财运
- **推断方向**：兄弟姐妹关系中存在分财议题 / 男命婚姻中配偶易损（分手 / 健康）/ 父亲早损（古法）
- **限制**：身弱用比劫时不构成"夺"；有食伤通关（比劫生食伤、食伤生财）时缓解
- **交叉引用**：lookup_tables.md §五 十神矩阵

### 2.4 财星无根

- **机制**：财星仅天干透出，地支无藏 → 浮财
- **结构条件**：财星天干透 + 四柱地支（含藏干）无财之同气
- **适用维度**：财运 / 婚姻（男命）/ 父亲
- **推断方向**：财来财去难积 / 男命妻子飘忽（不稳定 / 远距离）/ 与父缘分浮泛
- **限制**：行运补财根时缓解；若日主极旺则浮财亦可发挥
- **交叉引用**：basics.md §一 通根 / lookup_tables.md §二 地支藏干

### 2.5 财官两旺

- **机制**：财生官旺 → 财养官、官护财，名利可成
- **结构条件**：财星 + 官星都透干且都有根；身能任之
- **适用维度**：事业 / 婚姻 / 财运 / 性格驱动
- **推断方向**：事业与财运双轨发展 / 配偶有助于事业 / 中年后名利双收倾向
- **限制**：身弱不能任时反为"财杀党党"压身；命局缺印则官旺无依
- **交叉引用**：basics.md §六.3 配印 / 配杀 / 配比

## 三、官杀类断语

官杀（正官 / 七杀）= 克我者 = 规则 / 压力 / 子女（男命）/ 夫星（女命）。

### 3.1 伤官见官

- **机制**：伤官克正官 → 伤官旺时正官被克
- **结构条件**：伤官透干并旺 + 正官同时透出或显
- **适用维度**：事业（男）/ 婚姻（女）/ 父亲（间接）/ 性格驱动
- **推断方向**：与权威 / 上级关系紧张 / 事业上有"自立 vs 体制"的张力 / 女命婚姻波折
- **限制**：伤官佩印时印克伤、转为"化伤生身"；伤官生财时财通关化伤为财
- **交叉引用**：basics.md §六.3 配印 / 配杀 / 配比

### 3.2 官星无气

- **机制**：官星弱（失令 + 无根 / 被合走 / 被克破）→ 官的功能失效
- **结构条件**：官星天干透或藏，但月令非官、地支无官根、且被冲合或克
- **适用维度**：事业 / 婚姻（女）/ 子女（男）
- **推断方向**：男命子女缘薄或晚 / 女命夫星不显（晚婚 / 配偶不得力）/ 事业难有正式职位
- **限制**：身弱用比劫扶身时官无气可能反吉（避免压身）；行运补官则可补
- **交叉引用**：lookup_tables.md §十一 长生十二宫

### 3.3 杀印相生

- **机制**：七杀生印、印生身 → 杀气化为印之资源 → 压力转动力
- **结构条件**：七杀透或显 + 印星贴坐 + 身有根能任
- **适用维度**：事业 / 性格驱动 / 学习
- **推断方向**：高压环境下能借压力升华（如读研 / 进入高竞争行业 / 学术专精）/ 性格中有"被驱动 + 转化"的特质
- **限制**：印星虚弱无力化杀时不成立；身弱无根时杀为压身忌
- **交叉引用**：basics.md §六.3 配印 / 配杀 / 配比

### 3.4 七杀无制

- **机制**：七杀强 + 无食神制杀 + 无印化杀 → 杀气直接压身
- **结构条件**：七杀透或地支多杀 + 命局缺食伤 / 缺印
- **适用维度**：健康倾向 / 性格驱动 / 重大变故
- **推断方向**：易受打压 / 健康警示（特别外伤、急病、压力相关）/ 性格中有"易受外力击穿"特征
- **限制**：行运补食伤或印则化解；身极旺反需杀为用
- **交叉引用**：basics.md §六.3 配印 / 配杀 / 配比

### 3.5 时上偏官

- **机制**：时柱见七杀（"时上一位贵"）→ 子女宫位为压力之神
- **结构条件**：时柱地支或天干为七杀，且杀有根
- **适用维度**：子女（男命）/ 性格驱动 / 晚段事业
- **推断方向**：男命子女晚得或独子（古法）/ 子女个性较强 / 中晚年仍有事业压力但能有所成
- **限制**：杀须有制（食神或印）方为"贵"；杀无制反凶
- **交叉引用**：basics.md §六.3 配印 / 配杀 / 配比

## 四、食伤类断语

食伤（食神 / 伤官）= 我生者 = 表达 / 创造 / 子女（女命）。

### 4.1 伤官泄秀

- **机制**：伤官当令 + 身能担 → 伤官泄秀气（智慧 / 才华外显）
- **结构条件**：月令为伤官 + 日主有根能担 + 伤官气流通（有印制 / 有财泄）
- **适用维度**：性格驱动 / 学业 / 事业 / 表达创造
- **推断方向**：才气外显（善表达 / 善创作 / 思维敏锐）/ 学业上有"专精领域"特征
- **限制**：身弱担不起时为"泄气过甚"反凶；伤官无制时易为"才气张扬过度"
- **交叉引用**：basics.md §六.3 配印 / 配杀 / 配比

### 4.2 食神制杀

- **机制**：食神克七杀 → 食神驯服七杀，化压为创造
- **结构条件**：食神 + 七杀都透或显 + 食神能制（有根）
- **适用维度**：事业 / 性格驱动 / 健康（缓解杀压）
- **推断方向**：用创造性方式化解压力 / 在专业领域有突破 / 身心能在压力下保持柔韧
- **限制**：食神弱无法制时不构成；身弱时食神被夺则破局
- **交叉引用**：basics.md §六.3 配印 / 配杀 / 配比

### 4.3 食伤过旺

- **机制**：食伤多透或多根 → 泄身过甚
- **结构条件**：食伤天干并透 + 地支食伤根多 + 日主弱
- **适用维度**：健康倾向 / 性格驱动 / 子女（女命）
- **推断方向**：身心消耗大 / 想得多做得多难放松 / 女命子女缘上有"操心多 / 身体消耗"特征
- **限制**：身旺时食伤过旺反为正用；有印克伤食时缓解
- **交叉引用**：basics.md §五 用神

### 4.4 伤官配印

- **机制**：伤官旺 + 印克伤官 → 印化伤之锐为有体系输出
- **结构条件**：伤官当令 + 印星贴坐能克伤
- **适用维度**：学业 / 事业 / 性格驱动
- **推断方向**：才气有体系（学者型 / 研究型）/ 在学术 / 教育领域有发展 / 性格中有"锋芒 + 自律"
- **限制**：印虚弱时无法制，"形成立用打折"；印过旺则克伤过甚反成内耗
- **交叉引用**：basics.md §六.3 配印 / 配杀 / 配比

### 4.5 食神生财

- **机制**：食神生财 → 才华变现
- **结构条件**：食神透或显 + 财星贴坐受食生
- **适用维度**：事业 / 财运 / 性格驱动
- **推断方向**：通过创造 / 输出获得物质回报 / 适合靠手艺 / 内容 / 服务赚钱 / 中年后有"才华变实利"窗口
- **限制**：食神被枭夺时不成立；身弱担不起财食并发时反为忌
- **交叉引用**：basics.md §五 用神 / §六 格局判定

## 五、比劫类断语

比劫（比肩 / 劫财）= 同我者 = 兄弟姐妹 / 同辈竞争 / 自我能量。

### 5.1 比劫成群

- **机制**：原局多比劫 → 兄弟多 / 竞争意识强
- **结构条件**：天干比劫多透或地支比劫多根
- **适用维度**：兄弟姐妹 / 性格驱动 / 财运（间接）
- **推断方向**：兄弟姐妹众或与同辈关系密切 / 性格中有"集体感 + 抗压"特征 / 财运中有"分财"风险
- **限制**：身弱用比劫时为正面（帮身）；财官健旺命局比劫多则需克泄
- **交叉引用**：basics.md §二 十神

### 5.2 群比争财

- **机制**：多比劫同时夺一财 → 财弱难守
- **结构条件**：财星仅一处 + 比劫多于两处
- **适用维度**：财运 / 婚姻（男命）/ 兄弟姐妹
- **推断方向**：财上易被分（家庭 / 兄弟 / 朋友圈频繁分摊）/ 男命婚姻中有"竞争对手"暗象 / 兄弟分财议题显著
- **限制**：有食伤通关或官杀制比则缓解；身弱用比劫时不构成"争"
- **交叉引用**：lookup_tables.md §五 十神矩阵

### 5.3 日时双冲

- **机制**：日柱与时柱完全相冲（如戊戌 vs 壬辰）→ 自我宫与子女宫 / 晚段宫直接对冲
- **结构条件**：日柱与时柱天干 + 地支均为相冲关系
- **适用维度**：婚姻 / 子女 / 重大变故 / 性格驱动
- **推断方向**：与配偶有结构性张力（性格相反或长期分居）/ 与子女关系上有阶段性冲突 / 中年后自我位置与子女发展有拉扯
- **限制**：原局有合化通关时缓解（如有支引出三合）；冲为动而未必为破，须配合大运观察
- **交叉引用**：lookup_tables.md §八 地支六冲 / basics.md §四 合冲刑害伏吟

## 六、特殊结构断语

不属于纯十神类，但机制清晰、可循推演的特殊命理结构。

### 6.1 魁罡日

- **机制**：戊戌 / 庚辰 / 庚戌 / 壬辰 四日为魁罡，性刚果决
- **结构条件**：日柱为四魁罡之一
- **适用维度**：性格驱动 / 重大变故 / 婚姻（女命特别）
- **推断方向**：性格中有"决断 / 不肯认输"特质 / 一生有几个"冲魁罡"的关键节点（辰冲戌、丑刑戌、未刑戌）/ 女命婚姻有挑战
- **限制**：身弱时刚气有度无力；身旺有印扶为"魁罡格"之吉
- **交叉引用**：basics.md §6.5 魁罡格 / 魁罡日的细则与流派选择

### 6.2 羊刃倒戈

- **机制**：羊刃为劫财之极（戊见午、丙见午、庚见酉等）；羊刃所在支被冲 → 刚气反伤
- **结构条件**：原局有羊刃 + 大运 / 流年冲羊刃位
- **适用维度**：健康倾向 / 重大变故
- **推断方向**：身体上的急性事件（外伤、突发病）/ 人事上的剧烈冲突
- **限制**：身弱命局羊刃为帮身用神时被冲反为减弱；身旺命局羊刃倒戈方真凶
- **交叉引用**：lookup_tables.md §13.2 羊刃

### 6.3 寒暖燥湿失衡

- **机制**：原局五行配置过寒（金水多火少）/ 过暖（火多水少）/ 过燥（火土多水木少）/ 过湿（水木多火土少）→ 调候不到位
- **结构条件**：四柱五行严重失衡 + 缺调候用神
- **适用维度**：健康倾向 / 性格驱动
- **推断方向**：长期体质偏向（寒局 → 阳虚怕冷 / 暖局 → 火气大易上火 / 燥局 → 体液不足 / 湿局 → 痰湿堆积）/ 性格中有偏极特征
- **限制**：行运补足调候时缓解；命局有通关之神时不致严重
- **交叉引用**：basics.md §五.1 用神判断 / §三.2 季节与五行

### 6.4 库冲（开库）

- **机制**：辰戌冲 / 丑未冲为"库冲"——两库相冲，库藏干被引出
- **结构条件**：原局有库（辰 / 戌 / 丑 / 未 之一或多个）+ 大运 / 流年来对宫库冲
- **适用维度**：重大变故 / 婚姻 / 父亲 / 母亲（视库藏内容）
- **推断方向**：库中藏神（如戌中丁火、辰中癸水）被引出参与命局 → 该神所代表的事件维度有重大变动
- **限制**：库未冲时藏神入墓不显；同时冲两库时双库俱开，须综合
- **交叉引用**：basics.md §四.1 库冲与库合 / lookup_tables.md §八 地支六冲

### 6.5 三刑全启

- **机制**：寅巳申三刑、丑戌未三刑（三字皆备时三刑成立）
- **结构条件**：流年 + 大运 + 原局凑齐三刑三字
- **适用维度**：重大变故 / 健康倾向 / 多线议题
- **推断方向**：多线议题在同年同时显化（学业 / 关系 / 健康 / 家庭至少两类同时动）/ 体感"事不大但密集"
- **限制**：仅二字未成三时为"半刑"，能量小于三字全；三字皆备但有合化时刑力减
- **交叉引用**：lookup_tables.md §九 地支三刑

### 6.6 空亡逢冲

- **机制**：原局空亡支被流年冲 →"空中带动"，空亡之支被强制激活
- **结构条件**：原局有空亡支（日柱或年柱旬空）+ 流年 / 大运冲该支
- **适用维度**：早年环境（年空）/ 重大变故 / 健康倾向
- **推断方向**：空亡所代表的本盘资源被强制激活 → 通常为"被迫面对 + 伴随震荡"型事件
- **限制**：仅日柱空亡为主用，年柱空亡为旁证；空被合不算"动"
- **交叉引用**：basics.md §7.3 解空条件 / lookup_tables.md §十二 空亡

### 6.7 月柱伏吟

- **机制**：流年柱与月柱完全相同 → 月柱所代表的"父母 / 中年事业 / 月令气场"被复刻强化
- **结构条件**：流年 = 原局月柱（如月柱丁酉、流年丁酉）
- **适用维度**：父亲 / 母亲 / 事业 / 重大变故
- **推断方向**：父母维度的实质性事件年（健康 / 关系 / 居住）/ 事业关键节点 / 中年关键转折
- **限制**：月柱伏吟优先级高于年柱伏吟，但低于日柱伏吟；身弱命局伏吟为"重压"
- **交叉引用**：lookup_tables.md §八 地支六冲（伏吟与反吟）

## 维护与扩展

- **新增断语**：从命主跑测中遇到的"未覆盖"情况增量补；新条目须满足"机制清晰可循"边界
- **修订断语**：实证发现某条断语机制描述不准 / 限制条件不完整 → 修订
- **不收录**：纯口诀类（红鸾、孤辰、寡宿、丧门、吊客、披麻、白虎、童子煞、绞煞、灾煞、劫煞等）保持剔除
- **优先级**：当多条断语同时适用某维度时，按"机制契合度 + 触发强度"综合判断主断语，其他作辅证
