## 一、什么是八字 / 命局

"八字"是用**八个字**（四组天干地支）记录一个人出生的年、月、日、时——即"四柱"，每柱含一个天干、一个地支。八个字加起来即一个人的命局。

| 柱 | 含义 |
|---|---|
| 年柱（年干 + 年支） | 祖辈 / 早年环境 / 远方 / 大社会背景 |
| 月柱（月干 + 月支） | 父母 / 家庭 / 中年事业 / 月令气场（最旺） |
| 日柱（日干 + 日支） | **日干 = 命主本人**；日支 = 配偶宫、夫妻位 |
| 时柱（时干 + 时支） | 子女 / 晚年 / 远方 / 行动方向 |

**日主 = 八字中的"我"**。命局所有分析都以日主为核心。

> 例：`戊戌日` 的人，"戊土" 就是这个人的本质属性。所有用神判断都从"戊土日主"出发。

## 二、十神：十种能量角色

"十神"不是十个神，是**十种能量角色**，描述外来能量与日主的关系。

### 2.1 十神快速对照表

| 十神 | 与日主的关系 | 现实角色 / 能量 |
|---|---|---|
| **比肩** | 与我同性同气 | 同辈、合伙人、自我能量、行动力 |
| **劫财** | 与我同气但异性 | 兄弟姐妹、竞争者、消耗型同伴、冲动消费 |
| **食神** | 我所生且温和 | 温和的创作、艺术、孩子、表达 |
| **伤官** | 我所生但激烈 | 批判性思考、独立创作、不守规则、灵感 |
| **偏财** | 我克者但流动 | 副业、机会型收入、流动资源 |
| **正财** | 我克者且稳定 | 正式工资、固定资产、男命的妻子 |
| **七杀** | 克我但强烈 | 巨大压力、目标驱动、考验、男命的儿子 |
| **正官** | 克我但温和 | 规则、正式职位、社会身份、男命的女儿 |
| **偏印** | 生我但偏门 | 非主流学问、玄学 / 灵性、独特天赋 |
| **正印** | 生我者 | 母亲、师长、学历、精神滋养、保护 |

> 精确的"五种关系 × 阴阳同异 → 十神"推导矩阵见 [`lookup_tables.md`](./lookup_tables.md) §五。

### 2.2 简化记忆口诀

> "**印**滋养我，**比劫**同我，**食伤**我生，**财**我克，**官杀**克我"

### 2.3 阴阳同性 vs 异性

每个十神又分**阴阳**：

- 同性相见 → 偏（偏印、比肩、食神、偏财、七杀）
- 异性相见 → 正（正印、劫财、伤官、正财、正官）

阴阳的差异决定能量的"刚柔"：偏更刚烈、正更温和。

### 2.4 男命 vs 女命的十神角色

部分十神在男女命中代表的"亲属角色"不同：

| 十神 | 男命 | 女命 |
|---|---|---|
| 正财 | 妻 | （仅作财） |
| 偏财 | 偏妻 / 父亲 | 父亲 |
| 七杀 | 儿子 | 偏夫 / 情人 |
| 正官 | 女儿 | 正夫 |
| 食神 | 女儿 / 晚辈 | 女儿 |
| 伤官 | 儿子 / 晚辈 | 儿子 |

> 男命的妻星看正财 / 偏财，子女星看七杀 / 正官；女命的夫星看正官 / 七杀，子女星看食神 / 伤官。具体哪一星为主、哪一星为偏，需结合该星在原局是否透干、是否得地综合判断。

## 三、五行的现实含义（以戊土日主为例）

五行是 **木 / 火 / 土 / 金 / 水**。它们之间有 **生 / 克** 关系：

```
生：木 → 火 → 土 → 金 → 水 → 木（循环）
克：木 → 土，土 → 水，水 → 火，火 → 金，金 → 木
```

### 3.1 戊土日主的五行 → 十神映射

| 五行 | 对戊土日主是什么十神 | 现实代表的能量 |
|---|---|---|
| 火 | 印星（生我） | 学习 / 师长 / 精神支撑 / 内在火种 |
| 土 | 比劫（同我） | 自我能量、行动力、固守 |
| 金 | 食伤（我生） | 输出、创作、表达、技能 |
| 水 | 财星（我克） | 现实资源、工作回报、钱、男命之妻 |
| 木 | 官杀（克我） | 外部压力、规则、男命之子女 |

> 同样的"金"，对**戊土日主**是"输出 / 表达"（食伤），但对**辛金日主**就是"自我"，对**乙木日主**就是"压力 / 规则"。所以阅读分析时一定要先看日主。

### 3.2 季节与五行

每个季节有当令的五行——出生在该季节，对应五行能量最旺。

- 春季（寅卯辰月）当令 **木**：草木生发
- 夏季（巳午未月）当令 **火**：阳气最盛
- 秋季（申酉戌月）当令 **金**：收敛肃杀
- 冬季（亥子丑月）当令 **水**：寒冷潜藏
- 四季月（辰戌丑未）当令 **土**：转换枢纽

**月支**最重要，它代表"出生季节"，对日主能量影响最大。

> 月支与季节五行的精确对应表见 [`lookup_tables.md`](./lookup_tables.md) §四。

### 3.3 戊土日主的"季节体感"

- 戊土生于春（寅卯辰）→ 木旺克土，土被克泄而虚 → 偏弱
- 戊土生于夏（巳午未）→ 火生土，土厚实 → 偏旺
- 戊土生于秋（申酉戌）→ 金泄土气 → 偏弱
- 戊土生于冬（亥子丑）→ 水冷土寒，需火调候 → 弱且寒
- 戊土生于四库月（辰戌丑未）→ 土比肩自气最厚 → 旺

> 例：戊土生于酉月（仲秋），戊土于酉为死地——失令明确，这是判"偏弱身"的第一条线索。其余日主的"季节体感"均可按"日主五行 vs 月令季节五行"的生克关系类推。

### 3.4 藏干使用的边界规则（Caveat）

地支藏干有 **本气 / 中气 / 余气** 三层结构（精确藏干表见 [`lookup_tables.md`](./lookup_tables.md) §二）。推演时容易出现的错误用法是把藏干当成天干一样彼此发生作用。本节明确藏干使用的边界。

#### 规则一：藏干内部不互相生克

藏干彼此之间 **不发生五行生克作用**——它们位于同一地支内部，层级与权重不同（本气主导），不能像天干那样横向互动。

> **常见误用**：看到未中藏丁（火）、己（土），就推"丁生己 → 丁被己泄气 → 火印根更虚"。这种推法错——藏干内部各自有自己的角色与权重，本气是"己土"主导这个支位，中气丁存在但不"被本气泄"。

> **正确用法**：推演未中丁作为火印根的强弱，看的是：
> 1. **位置（中气位）**：中气位置力本就薄
> 2. **本气主导效应**：未的本气是己土，这一支的主导效应是"土"（对戊土日主是比劫助身），不是"火"
> 3. **外层互动**：未与原局其他支的合冲刑害（如戌未刑）对未的影响

#### 规则二：本气主导，中气余气是辅助

地支推演时优先用 **本气**——它代表该地支的核心属性。中气、余气作为"弱效暗藏"，用来：

- 解释"为何此支虽属 X，但有 Y 之机"
- 或解释"特定情况下（如冲、合、刑、墓库开启），Y 被牵动"

不能把中气、余气当成与本气并列的能量推演。

#### 规则三：藏干受外部生克作用，首先看本气

外来天干 / 流年大运的支与原局某支发生生克 / 合冲刑害时，作用对象 **首先是该支的本气**。中气、余气受连带影响，但不是主受体。

> 例：寅与申冲——寅本气甲被申本气庚冲，这是主体；寅中藏丙（中气）、戊（余气）受连带牵动，但不是被冲的主角。

---

> 这三条规则是命理推演的护栏。所有大运 / 流年 / 验前事任务在引用藏干时都应遵守。引用时可写 "（依 `methodology/basics.md` §3.4 藏干使用的边界规则）"。

## 四、合冲刑害伏吟

每一步大运 / 流年的天干地支，会与原局发生互动。互动剧烈程度从轻到重：

| 互动 | 通俗解释 | 体感 |
|---|---|---|
| **合**（六合 / 三合 / 半合 / 三会） | 两个或多个能量被拉到一起、绑定 | 关系或局面被联动，可能转化方向 |
| **冲**（六冲） | 两个能量直接对抗 | 剧烈变动、被迫面对、突变 |
| **刑** | 持续的摩擦、损耗 | 暗伤、慢性问题、关系不和 |
| **害**（六害） | 暗中损害 | 不易察觉的损耗、关系阴影 |
| **伏吟** | 同字重叠（运的字 = 原局某字） | 旧模式重演、能量复刻 |
| **反吟** | 与原局某字六冲且天干同 | 强烈对抗、情绪剧烈波动 |

冲是术数里**变动信号最强**的一类，往往对应居住地、关系、工作、健康的实质性变化。
刑没有冲那么剧烈，但会带来"持续性的摩擦"。
半合的力量约为三合的一半。
三会比三合更直接（同方同气，无需化）。

> 具体的地支六合 / 三合 / 半合 / 六冲 / 三刑 / 六害组合，见 [`lookup_tables.md`](./lookup_tables.md) §六–十。

### 4.1 库冲与库合（戊土日主特别关注）

- **库冲**（辰戌冲、丑未冲）：两库相冲会"开库"——库中藏干被冲出，原本入墓未启的能量被释放
- **库合**（如卯戌合化火）：以"合"的方式柔和引动库中藏干，比冲温和

戊土日主的命局如果有**戌**（火库），那么戌中藏丁火（正印）的"开闭"成为一生关键变数：
- 见辰来冲 → 火库被冲开 → 丁火被引出（双刃，同时引水入局）
- 见卯来合 → 火库被柔和引动（一般为吉）
- 见未来刑 → 戌未刑，火库被刑动（中性偏动）

> 同理，水库（辰）开闭看戌冲、丑刑、子半合等；金库（丑）看未冲、戌刑等；木库（未）看丑冲、戌刑等。

### 4.2 盖头 / 截脚（运干运支自身的关系）

每一步大运 / 流年 = 一干 + 一支组合体。运干与运支之间的五行关系决定该步运的"内在和谐度"：

| 关系 | 定义 | 体感 |
|---|---|---|
| **盖头** | 运干克运支（上克下） | 外面看到的（干）与内在落地的（支）方向相反 → 表面有但落地打折 |
| **截脚** | 运支克运干（下克上） | 内在基础（支）反咬天干 → 干虽透但根反向被克 |
| **干支同气** | 干支五行一致或相生 | 内外协调，理想型 |

**例**：
- 辛卯运：辛金克卯木 → **盖头**（卯本气乙作为子女星 / 正官，地支根有了但天干层面被克）
- 甲申运：申金克甲木 → **截脚**（甲透干但坐金根 → 七杀虚透，无根可恃）

**解读时**：盖头 / 截脚不一定是"凶"，而是说"这一步运有内部张力"——具体吉凶要结合运的十神性质 + 用神方向综合判断。本气主导的判断仍按 [§3.4 藏干使用的边界规则](#34-藏干使用的边界规则caveat) 处理。

### 4.3 伏吟 / 反吟的分级

§四主表中已概念性提到伏吟（同字重叠）和反吟（同干六冲），实操中需精确到"哪一级"——不同分级的强度差异显著：

#### 伏吟分级

| 分级 | 触发条件 | 强度 | 体感 |
|---|---|---|---|
| **天干伏吟** | 运干 = 原局某天干（年/月/日/时干之一） | 中等 | 该天干所主柱的属性面被复刻强化 |
| **地支伏吟** | 运支 = 原局某地支 | 较强 | 支位实在，旧能量复刻；常带"似曾相识"的体感 |
| **柱伏吟** | 运的整柱 = 原局某柱（干支双重叠） | 最强 | 能量完全复刻，旧模式重演（如戊戌运 + 戊戌日 = 完整日柱伏吟） |

> 命主一生中**柱级伏吟**出现频次极低（受大运序列限制），出现时往往是"结构性高能量年/段"。**天干伏吟**与**地支伏吟**单独出现较常见，逐运推演时需明确指出是哪一级、对应原局哪一柱（年 / 月 / 日 / 时柱中哪一柱被复刻），不能笼统说"伏吟"。

#### 反吟分级

| 分级 | 触发条件 | 强度 |
|---|---|---|
| **天干反吟** | 运干与原局某天干相冲且同性 | 中等 |
| **地支反吟** | 运支与原局某地支相冲且邻支相同 | 较强 |
| **柱反吟** | 运的整柱与原局某柱完全相反（如丙申运冲庚寅时柱） | 最强 |

> 体感对照：**伏吟是"重来一遍",反吟是"剧烈对抗"**——前者表"复刻",后者表"撞击"。

## 五、用神 / 喜神 / 忌神

这是命理判断的**核心**。

| 概念 | 定义 | 通俗理解 |
|---|---|---|
| **用神** | 命局最缺、最需要补的能量 | "我最该补的" |
| **喜神** | 用神之外仍有助益的能量 | "次要补给" |
| **忌神** | 命局已过盛 / 再加就坏的能量 | "我最该避的" |
| **闲神** | 既不利也不害的中性能量 | "无所谓" |

### 5.1 用神判断的核心逻辑

简化版：

1. **看身强身弱**：日主在月令中是否得令？四柱中印比够不够？（令、地、势三方面综合）
2. **身弱**：用神是"扶身"的（印 / 比劫）；忌神是"耗身"的（财 / 官杀 / 食伤太过）
3. **身强**：用神是"耗身"的（食伤 / 财 / 官杀）；忌神是"扶身"的
4. **调候**：寒局喜火、热局喜水、燥局喜润、湿局喜燥（与扶抑结合判断）
5. **通关**：当多神并见、能量冲克剧烈时，需要中介五行"通关"（如金木相战需水通关）

> 用神判断是技术活，不是数清五行个数那么简单。

### 5.2 戊土日主的用神判断要点

戊土日主的常见用神组合：

| 出生月份 | 常见用神主线 | 古法调候 |
|---|---|---|
| 寅卯月（春木旺） | 火（生土制木）+ 土（自助） | 丙、癸 |
| 辰月（土旺但木余气） | 视格局而定 | 甲、丙、癸 |
| 巳午未月（夏火旺） | 水（润燥）+ 金（泄秀） | 癸、丙、甲 |
| 申月（金旺泄土） | 火（生身）+ 土（自助） | 丙、癸 |
| **酉月（金当令死地）** | **火（生身）+ 土（自助）** | **丙、癸** |
| 戌月（土旺金余气） | 视格局而定 | 甲、丙、癸 |
| 亥子丑月（水寒土冻） | 火（暖局）+ 土（堤防） | 丙、甲 |

> **调候 vs 扶抑的取舍**：古法调候给的是"季节平衡的标准答案"，但实际命局里"标准用神"未必能落实——例如调候要丙火，但命局丙不透或丙根空亡，调候即"打折"，须结合扶抑（看身强身弱）综合判断。当调候用神与扶抑用神不一致时（如"秋戊喜癸"但命局已金水成势），应以"扶抑优先、调候为辅"取舍。

### 5.3 大运用神可能调整

命局用神是"体"，**大运 / 流年用神** 在大体框架内可能"微调"：

- 比如某人命局喜火，但走到一步火太旺的运 → 那十年内"补火"反而过度，"补木 + 调候"才对
- 这种"大运层面的微调"是大运分析与流年分析的核心内容之一

## 六、格局判定

格局是命局的"主结构"，决定整体的"运作方向"。

### 6.1 格局取法的优先级

1. **月令本气透干** → 取本气所代表的十神格（最常见、最优先）
2. **月令中气透干** → 取中气所代表的十神格
3. **月令余气透干** → 取余气所代表的十神格
4. **月令藏干俱不透** → 看四柱其他柱透出最有力的十神

### 6.2 常见正格

| 格局 | 取法 | 性质 |
|---|---|---|
| 正官格 | 月令正官当令或透出 | 守规、温和、有秩序感 |
| 七杀格 | 月令七杀当令或透出 | 抗压、攻克、有目标驱动 |
| 正财格 | 月令正财当令或透出 | 务实、求稳、重资源积累 |
| 偏财格 | 月令偏财当令或透出 | 灵活、求机、重流动资源 |
| 食神格 | 月令食神当令或透出 | 温和创作、表达、享乐 |
| **伤官格** | **月令伤官当令或透出** | **批判、独立、不守规、灵感强** |
| 正印格 | 月令正印当令或透出 | 重学习、依附长辈、保护型 |
| 偏印格 | 月令偏印当令或透出 | 偏门学问、玄学倾向 |

> 例：戊土日主、月令酉金（戊见辛为伤官，戊见庚为食神），且天干透辛 → 伤官格成立。其他日主类推："月令本气透干"是格局取法的第一优先级。

### 6.3 配印 / 配杀 / 配比

主格之外，常需"辅神"协调：

- **伤官配印**：伤官泄身过甚，须印来生身、印克伤来制衡 → "伤官见印"成立时，可化伤官之锐为有体系的输出
- **七杀配印**：七杀克身，须印来化杀生身 → 杀印相生，压力转化为驱动力
- **比劫帮身**：身弱时同气助身 → 用比劫扶身

> 配印 / 配杀的"形 vs 用"差异：很多命局**形上**辅神成立（如月干透出印星），但**用上**辅神虚浮（如印星坐绝、坐空、被合走、无源）——形成立、用打折。这是格局判定后必须接着评估的一层，否则会高估辅神的实际效力。

### 6.4 从格

当日主弱到极点（无根、无印）且某一神（财 / 杀 / 食伤）势成一片时，可考虑"从格"——舍弃日主自身，顺势从他。

从格的极端条件：

- 日主无根（藏干都没有同气）
- 印星绝迹（无印来源）
- 某一神势成一片（财、杀、或食伤之一占绝对主导）

> **判从格须严格**：只要日支本气是日主同气、或天干有印透出且有根、或藏干有同气可恃，通常**不入从格**。从格判错的代价大——会把"扶抑命"误作"顺势命"，用神方向 180 度反向。

### 6.5 魁罡格 / 魁罡日的细则与流派选择

**四魁罡日**：庚辰、庚戌、壬辰、戊戌（日柱组合规则可循）。

**魁罡的传统断语**：
- 主性刚果决、聪明决断
- 喜身旺、喜见比劫扶身（魁罡叠见为佳）
- 忌财官透干（女命尤忌）
- 忌冲（"冲魁罡"为公认关键触发）

**"魁罡格" vs "魁罡日"**：
- 严格意义的"魁罡格"要求日柱魁罡 + 命局有其他魁罡日重叠 + 身旺有印 / 比扶 — 才算特殊格局成立
- 仅日柱为魁罡之一者，**只称"魁罡日"**，不升级为"魁罡格"
- 命主分析中应明确区分二者：日柱为魁罡之一是"日柱属性"层面的观察，不等于格局成立

**流派分歧：魁罡是否忌"刑"**：
- **严格派**：魁罡仅忌**冲**（六冲机制）
- **宽泛派**：魁罡兼忌**刑**（三刑亦属动支机制，丑刑戌、未刑戌触动魁罡日支同样为关键节点）

**本仓库选用宽泛派**——刑亦属动支，触动魁罡日支同样会引动结构变化；命主分析中遇辰冲戌、丑刑戌、未刑戌均列为魁罡触发节点，统一处理。

> 流派选择的代价：宽泛派会让"魁罡触发"的节点更多（含丑、未运/年），下游动态分析的预警密度更高；严格派只标辰运/年。本仓库选宽泛派的理由是"刑同属动支机制"——只要承认空亡可被刑动、合可被刑破，就应承认魁罡日支可被刑动。

## 七、空亡的实操理解

### 7.1 什么是空亡

六十甲子分六旬，每旬十干配十支，剩两支无对应天干 → 即"空亡"。

> 具体六旬 → 空亡两支查表见 [`lookup_tables.md`](./lookup_tables.md) §十二。

### 7.2 空亡的实际效应

- **支位力量减半**：空亡的地支所藏的十神 / 五行作用打折
- **"有名无实"**：藏干所代表的能量"挂在那里但用不上"
- **本气、中气、余气都受影响**：不只是表面的本气受影响，藏在中气、余气位置的能量也同步打折

### 7.3 解空的条件

| 触发 | 机制 | 体感 |
|---|---|---|
| 填实（再见同支） | 大运 / 流年再见相同地支 → 实力补齐 | "终于站稳了" |
| 冲（六冲来支） | 空亡支被冲 → "空中带动" | 突变、被迫面对，伴随动荡 |
| 合（六合 / 三合） | 被合住、被引动 | 柔和的连带、合中带动 |

### 7.4 空亡判读的实操要点

判空亡须结合：

- **空亡支藏干代表的十神是喜还是忌**：喜用之根落空 → 削弱有利能量；忌神之根落空 → 减轻不利压力
- **空亡支在哪一柱**：年柱空覆盖早年环境与远方；月柱空覆盖中年事业；日支空覆盖配偶宫；时柱空覆盖晚年与子女
- **空亡支的藏干层次**：本气、中气、余气都受影响——不只是本气受影响，藏在中气、余气位置的能量也同步打折

例：戊戌日生人（属甲午旬，旬空辰、巳）——
- 巳藏丙（戊之偏印）+ 庚（食神）+ 戊（比肩），且巳为戊之禄位
- 巳逢空时，**禄位失稳 + 印根折损 + 比肩之根虚浮 + 食神长生地折扣**
- 对喜用（火、土）的削弱远大于对忌神（金）的削弱（因金本气在酉、申，不在巳） → 整体不利

### 7.5 年柱旬空 vs 日柱旬空

传统主流以**日柱旬空为主用**。年柱旬空可作旁证——

- 年柱所属旬（按年干支查旬）的旬空两支若覆盖原局某些柱，可作"该柱实效更虚"的旁证
- 但不动摇主结构判断：是否入格、是否从、用神方向、强弱判断等仍以日柱旬空 + 整体扶抑为准

> 实操中：以日空为主分析空亡的实效折损；年空仅在日空与年空对同一支造成"双层空"时附加权重，或在年空削弱的恰好是关键忌神位时作为旁证记号。

## 八、大运 / 流年

### 8.1 大运（10 年一段）

以**月柱**为起点，按命主性别 + 年干阴阳决定排运方向（顺排 / 逆排），每 10 年一步。

排运方向规则：

- 阳男 / 阴女 → 顺排
- 阴男 / 阳女 → 逆排

每个人一生通常分析 8 步大运（约 80 年），覆盖人生主体阶段。

> 注：本仓库不让 AI 排盘。具体大运序列由专业排盘软件给出，AI 解读时直接读取 `八字静态分析_*.json` 中已排好的大运。

### 8.2 流年（每年一变）

每年的天干地支按六十甲子循环。流年与大运、原局发生新的互动 → 形成"年度命题"。

### 8.3 大运分析的"边界"

本仓库的大运分析**只做十年大运维度**——关注的是：

- 每一步运的整体性质
- 一生 80 年的宏观曲线
- 命局核心矛盾的大运解决路径
- 关键转折点（岁运并临、合冲刑触发、库开闭等）

**不下沉到流年级**。流年级展开如有需要，单独建立 `{干支}大运_流年分析.md` 文件（如 `甲午大运_流年分析.md`），不混入大运总览。

> 边界依据：参考 [`prompts/prompt_大运十年详解.md`](../prompts/prompt_大运十年详解.md) 的边界声明。

### 8.4 岁运并临（特殊关注）

当流年柱与大运柱**完全相同**时（如丙申年遇丙申大运），称"岁运并临"——能量峰值，机制清晰可解释，是大运中应特别标注的关键年份。

岁运并临年份的判定方法：检视命主每一步大运的干支，与该步大运覆盖的年份范围内的流年干支对照，若有完全相同者即为岁运并临。一生通常有 0-2 次。
