# 八字硬数据查表（lookup_tables）

> 本文档收录八字命理中**结构化、可枚举、有确定答案**的硬数据，供 AI 解盘时直接对表查询。
>
> **流派说明**：本表收录子平派主流通用数据。藏干本/中/余气次序、长生十二宫（火土同根）、地支六合化气等，凡传统流派少数分歧处，采用《子平真诠》《滴天髓》主线。
>
> **不收录**：
> - 排盘公式（年上起月、日上起时、起运天数）—— 由专业排盘软件负责，AI 不需要算
> - 概念解释和推理逻辑 —— 见 `basics.md`
> - 命主特定的速查（某命主的禄位、空亡、神煞命中情况等）—— 写在该命主目录下，不进通用查表

## 五、十神推导矩阵

以日主为中心，与"对方"的关系决定十神类型。同性 vs 异性进一步分偏 vs 正。

| 关系 | 阴阳同性 | 阴阳异性 |
|---|---|---|
| 生我 | **偏印**（枭） | **正印** |
| 同我 | **比肩** | **劫财** |
| 我生 | **食神** | **伤官** |
| 我克 | **偏财** | **正财** |
| 克我 | **七杀**（偏官） | **正官** |

**使用方法**（以**戊土日主**为例）：

1. 先看对方的五行：
   - 对方是火 → 生我（印）
   - 对方是土 → 同我（比劫）
   - 对方是金 → 我生（食伤）
   - 对方是水 → 我克（财）
   - 对方是木 → 克我（官杀）
2. 再看阴阳：
   - 戊（阳）遇丙（阳）→ 同性 → 偏印
   - 戊（阳）遇丁（阴）→ 异性 → 正印
   - 戊（阳）遇戊（阳）→ 同性 → 比肩
   - 戊（阳）遇己（阴）→ 异性 → 劫财
   - 戊（阳）遇庚（阳）→ 同性 → 食神
   - 戊（阳）遇辛（阴）→ 异性 → 伤官
   - 戊（阳）遇壬（阳）→ 同性 → 偏财
   - 戊（阳）遇癸（阴）→ 异性 → 正财
   - 戊（阳）遇甲（阳）→ 同性 → 七杀（偏官）
   - 戊（阳）遇乙（阴）→ 异性 → 正官

### 5.1 戊土日主的十神速查（示例）

| 五行 | 阳干 | 阴干 |
|---|---|---|
| 火（生我） | 丙 = 偏印 | 丁 = 正印 |
| 土（同我） | 戊 = 比肩 | 己 = 劫财 |
| 金（我生） | 庚 = 食神 | 辛 = 伤官 |
| 水（我克） | 壬 = 偏财 | 癸 = 正财 |
| 木（克我） | 甲 = 七杀 | 乙 = 正官 |

## 六、地支六合

两两相合，化气如下表。

| 组合 | 化气 |
|---|---|
| 子 + 丑 | 土 |
| 寅 + 亥 | 木 |
| 卯 + 戌 | 火 |
| 辰 + 酉 | 金 |
| 巳 + 申 | 水 |
| 午 + 未 | 土（一说"日月合"，化气有争议） |

**力量**：六合力量中等，弱于三合，强于半合。

**化与不化**：六合是否真化为某五行，须看：(1) 月令支持，(2) 化神在天干透出且有根，(3) 没有其他支冲合干扰。多数情况下为"羁绊合"——能量被绑住但未必转化。

## 七、地支三合 / 半合 / 三会

### 7.1 三合局

三个地支合化为一个五行局。三合的核心是"中字"（午、酉、子、卯之一）。

| 三字 | 化气局 |
|---|---|
| 寅 + 午 + 戌 | 火局 |
| 巳 + 酉 + 丑 | 金局 |
| 申 + 子 + 辰 | 水局 |
| 亥 + 卯 + 未 | 木局 |

### 7.2 半合规则

**含中字**的两字组合算半合，力量约为三合的一半：

| 半合（前半） | 化气 | 半合（后半） | 化气 |
|---|---|---|---|
| 寅 + 午 | 火 | 午 + 戌 | 火 |
| 巳 + 酉 | 金 | 酉 + 丑 | 金 |
| 申 + 子 | 水 | 子 + 辰 | 水 |
| 亥 + 卯 | 木 | 卯 + 未 | 木 |

**不含中字**的两字（如寅戌、巳丑、申辰、亥未）通常**不算半合**，可视为弱关联。

### 7.3 地支三会方

三个**同方位**的地支聚集，能量比三合更纯（同气连续，无需化）：

| 三字 | 方位 | 五行 |
|---|---|---|
| 寅 + 卯 + 辰 | 东方 | 木 |
| 巳 + 午 + 未 | 南方 | 火 |
| 申 + 酉 + 戌 | 西方 | 金 |
| 亥 + 子 + 丑 | 北方 | 水 |

**三会 vs 三合**：三会是"同方同气"，能量纯；三合是"长生 + 帝旺 + 库"，能量化。三会在地支盘面的"占位感"更直接，三合在天干透出与化神配合时更强。

## 八、地支六冲

对宫相冲，相距 180 度，能量直接对抗。

| 冲对 | 五行属性 |
|---|---|
| 子 — 午 | 水冲火 |
| 丑 — 未 | 土土相冲（库冲） |
| 寅 — 申 | 木冲金 |
| 卯 — 酉 | 木金相冲 |
| 辰 — 戌 | 土土相冲（库冲） |
| 巳 — 亥 | 火冲水 |

**特点**：六冲是术数中变动信号最强的互动，常对应居住地、关系、工作、健康的实质性变化。

**库冲**（丑未冲、辰戌冲）特殊：两库相冲会"开库"——库中藏干被冲出，原本入墓未启的能量被释放。

## 十二、空亡（旬空）

六十甲子分为六旬，每旬十天干配十地支，剩余两支即"空亡"（旬中无对应天干）。

| 旬首 | 旬末 | 空亡两支 |
|---|---|---|
| 甲子 | 癸酉 | 戌、亥 |
| 甲戌 | 癸未 | 申、酉 |
| 甲申 | 癸巳 | 午、未 |
| 甲午 | 癸卯 | 辰、巳 |
| 甲辰 | 癸丑 | 寅、卯 |
| 甲寅 | 癸亥 | 子、丑 |

**使用方法**：根据日柱所在的旬，查出该命主的空亡两支。如日柱是戊戌（在甲午旬，自甲午起十日：甲午、乙未、丙申、丁酉、戊戌、己亥、庚子、辛丑、壬寅、癸卯），则空亡为辰、巳。

**特点**：

- 空亡的支位"力量减半"或"实事虚化"——藏干所表达的十神 / 五行作用打折
- 遇冲、合可解空亡：填实（再见相同地支）→ 解空；冲（六冲来支）→ 空中带动；合 → 合中带动
- **年柱旬空 vs 日柱旬空**：传统主流以日柱旬空为主用；年柱旬空可作为旁证，但不动摇主结构判断

### 13.1 禄神（日干临官位）

| 日干 | 禄神位 |
|---|---|
| 甲 | 寅 |
| 乙 | 卯 |

**含义**：禄神所在地支为日主的"安身立命之位"。原局命中禄神主一生有立足点；禄神被空、被冲、被合走则需后天补强。

| 阳日干 | 羊刃位 |

| 亥卯未 | 卯 |

**含义**：将星主"统帅气场"，在群体中担当核心、有领导力。

### 13.4 华盖（三合局之库 / 末字）

**含义**：华盖主独立、智慧、艺术 / 精神倾向、易孤独感。落于日支或时支时为"内在精神世界"的主要标记。

### 13.5 驿马（三合局之冲位）

| 所属三合局 | 驿马位 |
