# 验前事方法论

> **验前事** = 在为命主推演未来之前，先用八字结构反向推断**已发生的若干事件**，
> 供命主逐条核对。这是中国传统命理建立可信度的标准动作——过去事件落得住，未来推演才有信任基础。
>
> 本文是验前事任务的**通用方法论**：定义任务的两层架构、事件维度框架、判定门槛、论证要求、输出格式。
> 具体的任务调度（输入定义、校验逻辑、工作流的步骤实例化）由 `prompts/验前事.md` 实现，
> prompt 应引用本文件而不重复其中规则。

## 一、角色与两层架构

### 1.1 角色定位

验前事任务是**反向推断**：用八字结构反向推断**已发生年份**的若干事件，让命主自行验证。

- **不是预测未来**：超过当前时间锚的年份不属于本任务
- **不是逐年扫描**：每年一段的展开属于流年分析任务范畴
- **是结构性钉点**：从命局结构出发，钉住具有家庭背景属性 + 能量冲突最强的若干事件

### 1.2 两层架构（先后递进）

验前事推断分两层：

| 层 | 任务 | 速度 | 计算依赖 |
|---|---|---|---|
| **第一层：原局断事** | 从原局结构直接断**长期型事件**（家庭背景、父母状况、早年经历、健康倾向、性格驱动）| 快 | 仅依赖静态分析三件套 |
| **第二层：流年触发** | 从大运 + 流年触发断**特定年份的高能量事件** | 慢 | 依赖大运 / 流年表 |

**先做原局断事，后做流年触发**——原局断事是"地基"（命主的轮廓），流年触发是"精度补"（在轮廓上钉具体年份）。两层之间是承接关系，不是并列。

> 设计动机：古人断"母亲早逝、少年丧亲、独立较早"这种**结构性家庭背景断语**根本不需要排大运 / 算流年，仅靠原局十神 + 关键结构组合即可。验前事方法论应当首先继承这一传统能力——快、稳、覆盖大事件——再用流年触发补具体年份精度。

### 1.3 与其他动态任务的边界

| 任务 | 时间方向 | 粒度 | 与验前事的区别 |
|---|---|---|---|
| 大运整体分析 | 跨一生 | 十年大运 | 含未来；只看大运层不下沉流年 |
| 流年分析 | 选定大运段 | 逐年扫描 | 含未来；扫描全部流年 |
| **验前事** | **仅过去** | 原局断事 + 跨多大运挑高能量年 | **仅推过去，不推未来** |
| 事件校验（未来任务）| 命主提供清单 | 评估命中度 | 命主先提供事件清单 → 评估 AI 解盘命中度 |

> 验前事是事件校验的**前置生成器**：本方法论产出的预测被命主标注后，
> 可作为事件校验的输入，闭环驱动 methodology 演化。

### 1.4 时间边界原则

- **只考虑当前时间锚之前的年份**（含已开始但尚未走完的当前流年的已发生段）
- 超过当前时间锚的年份**不允许出现在产出中**——超过即不是"验前"，是"测后"
- 时间锚优先级：命主静态文件 `_meta` 中明确给出 > 用户对话指明 > 系统当前年份
- 时间锚 ≤ 命主出生年 → 任务无意义，停止

## 二、原局断事层

### 2.1 设计目标

| 目标 | 实现方式 |
|---|---|
| **快** | 不依赖大运 / 流年；直接读静态分析三件套字段，按事件维度重组 |
| **不依赖外部计算** | 大运排盘、流年扫描均不需要 |
| **可校验** | 输出"事件类型清单"而非"单一具体事件"，命主逐项勾选命中 / 部分命中 / 未命中 |
| **建立信任** | 覆盖家庭、父母、早年、健康等命主自己会有清晰记忆的"长期型事件" |

### 2.2 与静态分析的关系

> **核心认知**：静态分析三件套（`file 1/2/3`）已经把绝大部分原局断事的素材准备好了。
> 原局断事层 = **对静态分析的"事件维度化"重组**——按"父 / 母 / 兄弟 / 婚 / 子 / 健康 / 早年 / 性格 / 变故"等维度抽取相关字段，不再独立推演。

这是为什么原局断事可以做到"快"——所有判断依据已经在静态分析里。

### 2.3 事件维度框架（9 个维度）

每个维度的判断依据 + 推断粒度：

| 维度 | 主要看的结构 | 静态分析字段（参考）| 推断粒度 |
|---|---|---|---|
| **父亲** | 偏财状态（男女命同看偏财为父）+ 年柱 | `file 1::ten_gods_mapping.branches_canggan` 中偏财位置 + `file 3::shensha_analysis.year_pillar` | 父亲健康 / 与父关系 / 父亲缺位 |
| **母亲** | 印星状态（正印、偏印）+ 月柱 | `file 1::ten_gods_mapping.stems` 印星 + `file 1::day_master_strength.supporting_caveats` 印根 + `file 2::structure_analysis.peiying_evaluation` | 母亲健康 / 与母关系 / 母亲缺位 / 母分身乏术 / 早年丧亲（候选） |
| **兄弟姐妹** | 比劫状态 | `file 1::day_master_strength.supporting_caveats` 比肩通根分析 | 兄弟之有无 / 与兄弟关系 / 兄弟得力与否 |
| **婚姻 / 配偶** | 男命：正财 / 偏财 + 妻宫；女命：正官 / 七杀 + 夫宫 | `file 3::male_specific.妻星位` / `妻宫` 或 `female_specific.夫星位` / `夫宫` | 婚姻早晚 / 配偶得力与否 / 婚姻稳定性 / 配偶代位象 |
| **子女** | 男命：正官 / 七杀 + 时柱；女命：食神 / 伤官 + 时柱 | `file 3::male_specific.子女星` / `子女宫` 或 `female_specific.子女星` / `子女宫` | 子女有无 / 子女缘分早晚 / 与子女关系 |
| **健康倾向** | 日主旺衰 + 用神状态 + 关键结构（魁罡 / 羊刃 / 库冲）| `file 1::day_master_strength` + `file 1::day_pillar_qualities` + `file 2::elements` 用神状态 | 长期体质倾向 / 易损系统（火虚 → 心血管、金过强 → 呼吸、水弱 → 肾等）|
| **早年环境** | 年柱 + 月柱 + 童年大运 | `file 1::chart_topology` + `file 3::shensha_analysis.year_pillar` + 童年大运 | 早年家境 / 早年迁移 / 早年家庭变故 / 独立较早倾向 |
| **性格驱动** | 日主 + 月支当令 + 格局 + 主要十神 | `file 1::ten_gods_mapping.summary` + `file 2::structure_analysis` + `file 3::personality_profile` | 性格底层驱动 / 行事风格 / 内在张力 |
| **重大变故倾向** | 魁罡 / 羊刃 / 寒暖失衡 / 三刑结构 / 重大冲克 | `file 1::day_pillar_qualities` + `file 2::structure_activation_hooks.unfavorable_activations` | 一生中重大转折点的结构性预警（仅作倾向，不指年份）|

> 不是每个命主每个维度都会触发——只有**结构上有显著倾向**的维度才纳入产出。
> 命主结构平和的维度（如比劫无明显特征 → 兄弟姐妹维度无可断之处）可以直接跳过，不强行展开。

### 2.4 推断粒度：事件类型清单（非单一具体事件）

**核心原则**：原局结构推得到的是"**与某维度相关的某种实质性挑战或特征**"，推不到"具体某年发生某具体事件"。

具体到表述：

| 允许 | 禁止 |
|---|---|
| ✅ 与母维度的某种实质性挑战（候选：早年丧亲 / 母亲长期健康问题 / 与母情感疏离 / 母亲长期不在身边 / 母分身乏术陪伴极少 之一或多个）| ❌ 母亲早逝 |
| ✅ 婚姻晚成或多波折 | ❌ 30 岁结婚 / 离过一次婚 |
| ✅ 健康警示倾向：心血管 / 内分泌相关系统 | ❌ 心脏病 / 糖尿病 |
| ✅ 兄弟姐妹缘分薄 | ❌ 没有兄弟姐妹 / 有一个姐姐 |

**为什么**：

- 古人能断"母亲早逝"是因为古代社会结构稳定，"印不利 = 母早逝"统计相关性高
- 现代社会同样的结构可能对应：早逝 / 健康问题 / 性格疏远 / 长期外出 / 离异 / 分身乏术 等多种情况——命理结构层面**无法区分**这些
- 给出**事件类型清单**让命主勾选实际命中——既不失锐度，又不易翻车

### 2.5 传统断语的引用

机制清晰可循的传统命理断语（如 **枭神夺食、财来破印、伤官见官、印星见冲、日时双冲、羊刃倒戈、比劫夺财、官星无气、印星无源** 等）是原局断事的有效语言——它们底层是十神 + 地支机制的组合应用，不是黑箱口诀。

完整的传统断语集（含每条的命理机制 + 推断方向 + 适用维度）见 `methodology/传统断语集.md`（待建立）。

> **边界**：只采用机制清晰可循的传统断语；剔除红鸾、孤辰、寡宿、丧门、吊客、披麻、白虎、童子煞等纯口诀类（与 `raw_paipan_processing.md` §三神煞过滤原则一致）。

## 三、流年触发层

### 3.1 角色定位

在原局断事建立轮廓后，流年触发层在**特定年份**钉具体事件——补足原局层"知道有这种事但不知道具体哪年"的精度缺口。

### 3.2 高能量年判定门槛（8 项）

只有满足下列**至少一项**的年份才算"结构性高能量年"，可纳入流年触发层候选。

#### 3.2.1 岁运并临

流年柱与大运柱完全相同（如 2016 丙申流年遇丙申大运）。

- **命理依据**：大运柱 = 流年柱 → 双倍能量集中显化
- **优先级**：极高
- **参考字段**：命主静态分析 `file 3::key_years_for_dynamic_analysis.岁运并临` 已显式列出

#### 3.2.2 冲空亡

流年支冲原局空亡支（"空中带动"——空亡先发动）。

- **命理依据**：空亡支平时虚浮，被冲时强制激活，伴随能量震荡
- **参考**：`methodology/basics.md §7.3` 解空条件
- **触发分级**：日空 > 年空（按日空主用、年空旁证）

#### 3.2.3 柱级伏吟

流年与原局某柱完全相同。按命理传统，伏吟优先级：

| 伏吟柱 | 含义 | 优先级 |
|---|---|---|
| 日柱伏吟 | 自我内核被复刻强化 | 最高 |
| 月柱伏吟 | 事业 / 中年 / 父母气场被复刻 | 高 |
| 时柱伏吟 | 晚段 / 子女 / 远方气场被复刻 | 高 |
| 年柱伏吟 | 早年 / 家族气场被复刻 | 中 |

#### 3.2.4 三刑同时触发

如丑戌未三刑全开、寅巳申三刑全启（流年 + 大运 + 原局凑齐三支）。

- **命理依据**：三字皆被牵动，能量纠结，多线议题在同年并发
- **参考**：`methodology/lookup_tables.md §九` 地支三刑

#### 3.2.5 三合 / 三会局完成

流年支 + 大运支 + 原局支凑齐三合或三会（**首次完整成立**最关键）。

- **命理依据**：三合 / 三会的能量化为某一五行，对全局结构产生质变
- **参考**：`methodology/lookup_tables.md §七`

#### 3.2.6 关键用神首次"透干 + 得地"

命局缺位或虚位的用神在某流年首次完整出现（天干透出 + 地支有根）。

- **命理依据**：用神从"虚位"到"实位"的临界点，全局结构由"挣扎期"切换到"开花期"
- **判定要点**：必须**首次**到位才算高能量年；持续到位的年份归流年分析任务

#### 3.2.7 大运首末年

大运交接的结构性临界点。

- **大运起换年（首年）**：旧能量收束 + 新能量开启的过渡期；体感"前后两半"
- **大运末年**：旧大运能量收口

#### 3.2.8 关键之神首次到位或受重制

关键之神 = 夫星 / 妻星 / 子女星 / 当下大运用神。

- **首次到位**：在某年首次以"透干 + 得地"形式出现
- **受重制**：在某年同时被冲、合、刑、克多重作用

### 3.3 触发叠加规则

> 同年触发多个门槛 → **只算一年**（不要拆成多条事件），但触发清单必须**列全所有触发**。
> 多门槛叠加的年份在结构性显著度排序中权重更高，是优选事件年的首要候选。

### 3.4 与原局断事层的承接

流年触发层的优先取向：**为原局断事层中已经标记的事件维度提供具体年份精度**。例如：

- 原局断事层断"与母维度有挑战" → 流年触发层在候选高能量年中标记**哪一年最可能是该事件的发生年**（如某年印星受重制、月柱伏吟、印根冲空等）
- 原局断事层断"婚姻晚成或多波折" → 流年触发层标记**妻星 / 夫星受冲合 / 妻宫 / 夫宫被冲 / 三合化忌神** 的关键年份

承接的方向是"**原局断事层 → 流年触发层提供具体年份精度**"，反之则不必（流年触发层独立挑出的年份未必都对应原局已有维度，但应优先提及与原局事件相关的年份）。

## 四、论证要求

### 4.1 命理链条要求

#### 原局断事层（3 步链）

```
1. 原局结构：哪个 / 哪些字段（参考静态分析三件套；可引用具体字段路径）
2. 机制：基于的命理机制（如枭印夺食、印星受冲、财星临墓等；可引用 methodology/传统断语集.md 中的对应条目）
3. 推断方向：与某维度相关的某种倾向（多候选并列）
```

#### 流年触发层（4 步链）

```
1. 原局结构：本造静态命局的某一结构特征
2. 大运背景：当年所处大运对该结构的影响
3. 流年触发：流年支 / 干如何触发该结构
4. 推断方向：上述三层叠加 → 推断什么类型的事件
```

> 任一环缺失视为不合格——不允许只给结论不给链条。

链条用编号列表或表格组织，**不允许**把多个机制糊成一段散文。

### 4.2 事件描述三维度

每条推断（无论原局层还是流年层）的事件描述必须落到三个维度：

| 维度 | 取值 |
|---|---|
| **维度** | 学业 / 健康 / 感情 / 家庭 / 居住 / 财务 / 事业 / 人际 / 父母 / 兄弟姐妹 / 子女 中之一或多个 |
| **方向** | 顺 / 逆 / 突变 / 持续 / 缺位 |
| **强度** | 轻微 / 显著 / 重大 |

### 4.3 模糊词汇禁用

**禁用模糊词**：避免"大概""可能""差不多""或许有变化""有时"这类——这类词等于不论断，会让验前事失去校验意义。

**允许的限定方式**（不是模糊化）：

- **概率限定**：用"高概率""倾向于" —— 不用"也许""可能"
- **粒度限定**：用"事件类型清单而非具体细节"
- **多候选并列**：原局断事层允许给出多个候选事件类型（命主勾选）

### 4.4 可证伪点

每条推断必须附**可证伪点**：

- **原局断事层**的可证伪点是"维度级别"（如"若命主与母无任何特殊议题，则本条证伪"）
- **流年触发层**的可证伪点是"年份级别"（如"若 YYYY 年命主无此类事件，则本条证伪"）

没有可证伪点的推断 = 万能套话，应重写。可证伪点必须**与推断事件等价**——不能太宽（永远命中）也不能太窄（吹毛求疵）。

## 五、产出规模约束

| 层 | 规模 | 备注 |
|---|---|---|
| 原局断事层 | 涉及 3-7 个事件维度（视命主原局结构特征）| 不强求全部 9 个维度都展开；结构平和的维度直接跳过 |
| 流年触发层 | 4-8 个事件年（极少数命主可至 10 年）| 多于 10 年即落入流水账 |

> 命主出生至时间锚不足 4 年 → 验前事任务可能无法成立，建议放弃流年触发层或仅做原局断事层。

## 六、输出格式

### 6.1 完整文档章节结构

| 章节 | 内容 | 对应方法论层 |
|---|---|---|
| §0 边界声明 | 时间锚 / 覆盖年份范围 / 覆盖大运段表 | 共通 |
| §1 原局断事 | 按事件维度组织（父 / 母 / 兄弟 / 婚 / 子 / 健康 / 早年 / 性格 / 变故 中触发的几个）| 第一层 |
| §2 流年触发候选清单 | 按 §三 8 门槛扫描的全部候选 + 每个触发的门槛 + 触发强度 | 第二层 |
| §3 流年触发推断 | 从候选中优选 4-8 年，按 §6.3 结构展开 | 第二层 |

## 七、维护与迭代

### 7.1 修订动机

只有以下动机才修订本文档：

1. **新增事件维度**：从更多命主验前事跑测中识别出当前 9 个维度未覆盖的、有结构意义的新维度
2. **新增 / 删除流年触发层判定门槛**：实证发现新的高能量结构 / 原门槛实际不构成高能量
3. **格式约定调整**：产出文件结构演进时同步更新
4. **两层关系调整**：当前是"原局断事 → 流年触发"先后递进，未来若发现并行更合理则调整
5. **传统断语集启用**：当 `methodology/传统断语集.md` 建立后，本文 §2.5 的相关引用应同步更新

### 7.2 不修订的情况

- 命主特定的发现 → 写入命主级文档，不上升到本方法论
- 单次跑测命中度低 → 调整该次跑测的具体推断措辞，不改方法论
- 流派偏好变化 → 重大决定，应整体讨论
