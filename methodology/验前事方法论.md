# 验前事方法论

> **验前事** = 在为命主推演未来之前，先用八字结构反向推断**已发生的若干高能量事件**，
> 供命主逐条核对。这是中国传统命理建立可信度的标准动作——过去事件落得住，未来推演才有信任基础。
>
> 本文是验前事任务的**通用方法论**：定义任务的角色边界、判定门槛、论证要求、输出格式与产出规模。
> 具体的任务调度（输入定义、校验逻辑、工作流的步骤实例化、与具体命主的绑定）由 `prompts/验前事.md` 实现，
> prompt 应引用本文件而不重复其中规则。

## 一、角色与任务边界

### 1.1 角色定位

验前事任务是**反向推断**：用八字结构反向推断**已发生年份**的若干高能量事件，让命主自行验证。

- **不是预测未来**：超过当前时间锚的年份不属于本任务
- **不是逐年扫描**：每年一段的展开属于流年分析任务范畴
- **是结构性钉点**：从命局结构出发，钉住能量冲突最强的若干年份（4-8 年）

### 1.2 与其他动态任务的边界

| 任务 | 时间方向 | 粒度 | 与验前事的区别 |
|---|---|---|---|
| 大运整体分析 | 跨一生 | 十年大运 | 含未来；只看大运层不下沉流年 |
| 流年分析 | 选定大运段 | 逐年扫描 | 含未来；扫描全部流年 |
| **验前事** | **仅过去** | 跨多大运挑高能量年 | **仅推过去，不推未来**；只挑结构性高能量年 |
| 事件校验（未来任务）| 命主提供清单 | 评估命中度 | 命主先提供事件清单 → 评估 AI 解盘命中度 |

> 验前事是事件校验的**前置生成器**：本方法论产出的预测被命主标注后，
> 可作为事件校验的输入，闭环驱动 methodology 演化。

## 二、时间边界原则

- **只考虑当前时间锚之前的年份**（含已开始但尚未走完的当前流年的已发生段）
- 超过当前时间锚的年份**不允许出现在产出中**——超过即不是"验前"，是"测后"
- 时间锚优先级：命主静态文件 `_meta` 中明确给出 > 用户对话指明 > 系统当前年份
- 时间锚 ≤ 命主出生年 → 任务无意义，停止

## 三、高能量年判定门槛（8 项）

只有满足下列**至少一项**的年份才算"结构性高能量年"，可纳入验前事候选。

### 3.1 岁运并临

流年柱与大运柱完全相同（如 2016 丙申流年遇丙申大运）。

- **命理依据**：大运柱 = 流年柱 → 双倍能量集中显化
- **优先级**：极高
- **参考字段**：命主静态分析 `file 3::key_years_for_dynamic_analysis.岁运并临` 已显式列出

### 3.2 冲空亡

流年支冲原局空亡支（"空中带动"——空亡先发动）。

- **命理依据**：空亡支平时虚浮，被冲时强制激活，伴随能量震荡
- **例**：日柱旬空辰、巳的命主 → 亥年冲巳、戌年冲辰
- **参考**：`methodology/basics.md §7.3` 解空条件
- **触发分级**：日空 > 年空（按日空主用、年空旁证）

### 3.3 柱级伏吟

流年与原局某柱完全相同。按命理传统，伏吟优先级：

| 伏吟柱 | 含义 | 优先级 |
|---|---|---|
| 日柱伏吟 | 自我内核被复刻强化 | 最高 |
| 月柱伏吟 | 事业 / 中年 / 父母气场被复刻 | 高 |
| 时柱伏吟 | 晚段 / 子女 / 远方气场被复刻 | 高 |
| 年柱伏吟 | 早年 / 家族气场被复刻 | 中 |

### 3.4 三刑同时触发

如丑戌未三刑全开、寅巳申三刑全启（流年 + 大运 + 原局凑齐三支）。

- **命理依据**：三字皆被牵动，能量纠结，多线议题在同年并发
- **参考**：`methodology/lookup_tables.md §九` 地支三刑
- **典型体感**："今年怎么这么多事一起来"

### 3.5 三合 / 三会局完成

流年支 + 大运支 + 原局支凑齐三合或三会（**首次完整成立**最关键，因为是"从未到位 → 到位"的临界点）。

- **命理依据**：三合 / 三会的能量化为某一五行，对全局结构产生质变
- **参考**：`methodology/lookup_tables.md §七` 三合 / 三会
- **触发分级**：含中字（午、酉、子、卯）的三合 > 三会方位 > 半合

### 3.6 关键用神首次"透干 + 得地"

命局缺位或虚位的用神在某流年首次完整出现（天干透出 + 地支有根）。

- **命理依据**：用神从"虚位"到"实位"的临界点，全局结构由"挣扎期"切换到"开花期"
- **例**：原局缺木的命主 → 甲辰年（甲透干 + 辰中乙木为根 → 木印首次到位）
- **判定要点**：必须**首次**到位才算高能量年；持续到位的年份归流年分析任务

### 3.7 大运首末年

大运交接的结构性临界点。

- **大运起换年（首年）**：旧能量收束 + 新能量开启的过渡期；体感"前后两半"
- **大运末年**：旧大运能量收口
- **优先级**：中（不如前几项强，但作为辅助门槛常与其他门槛叠加）

### 3.8 关键之神首次到位或受重制

关键之神 = 夫星 / 妻星 / 子女星 / 当下大运用神。

- **首次到位**：在某年首次以"透干 + 得地"形式出现
- **受重制**：在某年同时被冲、合、刑、克多重作用
- **典型场景**：男命妻星暗藏未透 → 某年妻星首次明透；女命子女星无根 → 某年子女星首次得地

### 触发叠加规则

> 同年触发多个门槛 → **只算一年**（不要拆成多条事件），但触发清单必须**列全所有触发**。
> 多门槛叠加的年份在结构性显著度排序中权重更高，是优选事件年的首要候选。

## 四、论证要求

### 4.1 命理链条（4 步链）

每条推断必须显式展示完整链条：

1. **原局结构**：本造静态命局的某一结构特征
2. **大运背景**：当年所处大运对该结构的影响
3. **流年触发**：流年支 / 干如何触发该结构
4. **推断方向**：上述三层叠加 → 推断什么类型的事件

> 任一环缺失视为不合格——不允许只给结论不给链条。

链条用编号列表或表格组织，**不允许**把多个机制糊成一段散文。

### 4.2 事件描述三维度

每条推断的事件描述必须落到三个维度的具体值：

| 维度 | 取值 |
|---|---|
| **维度** | 学业 / 健康 / 感情 / 家庭 / 居住 / 财务 / 事业 / 人际 中之一或多个 |
| **方向** | 顺 / 逆 / 突变 / 持续 |
| **强度** | 轻微 / 显著 / 重大 |

三维度都必须显式给出，缺一不可。

### 4.3 模糊词汇禁用

**禁用模糊词**：避免"大概""可能""差不多""或许有变化""有时"这类——这类词等于不论断，会让验前事失去校验意义。

**允许的限定方式**（不是模糊化）：

- **概率限定**：用"高概率""倾向于" —— 不用"也许""可能"
- **粒度限定**：用"事件类型而非具体细节"

| 允许 | 禁止 |
|---|---|
| ✅ 重大健康警示 | ❌ 得了某某具体疾病 |
| ✅ 居住地变动 | ❌ 搬到了某某城市 |
| ✅ 重要关系开启或破裂 | ❌ 与某某具体的人发生关系 |
| ✅ 学业层级跃迁 | ❌ 考上了某某具体学校 |

> 粒度限定的本质：八字推命落得住的是"事件类型 + 方向 + 强度"，落不住的是"具体名字、地点、数字"——超出能力范围。

### 4.4 可证伪点

每条推断必须附**可证伪点**：一句话写明"若此年命主未发生此类事件，则本条推断证伪"。

- 这是给命主的明确校验锚
- 没有可证伪点的推断 = 万能套话，应重写
- 可证伪点必须**与推断事件等价**——不能太宽（永远命中）也不能太窄（吹毛求疵）

## 五、产出规模约束

- 一份验前事产出**通常 4-8 个事件年**，不超过 10 个
- 多于 10 年即落入流水账，违背"只挑高能量年"原则
- 少于 4 年视命主出生至时间锚的总年数：年数越长候选越多，最低不少于 4 年
- 候选清单（§1）可全部列出（不限数量），最终推断（§2）只取 4-8 年

> 命主出生至时间锚不足 4 年（如时间锚 = 命主 3 岁）时，验前事任务可能无法成立——
> 婴幼期事件归因更多在父母 / 家庭，命主自身无清晰记忆，建议放弃本次任务或仅作背景注脚。

## 六、输出格式

### 6.1 每年推断的固定结构

```
### YYYY 干支 · N 岁 · 一句话定性

#### 结构触发
（按 §三 8 项门槛中触发的几项，列全）

#### 命理链条
1. 原局：……
2. 大运：……
3. 流年触发：……
4. 推断方向：……

#### 推断事件
> 维度：……
> 方向：……
> 强度：……
>
> 文字描述（1-3 句话；禁用模糊词；粒度 = 事件类型而非具体细节）

#### 可证伪点
> 若此年命主未发生此类事件，则本条证伪
```

### 6.2 完整文档结构

按以下章节组织（参考 [`xty/charts/chart_001/yan_qian_shi.md`](https://github.com/kunlin-47/xty/blob/main/charts/chart_001/yan_qian_shi.md) 的产出范式）：

| 章节 | 内容 |
|---|---|
| §0 边界声明 | 时间锚 / 覆盖年份范围 / 覆盖大运段表 |
| §1 高能量年候选清单 | 按 §三 8 门槛扫描的全部候选 + 每个触发的门槛 + 触发强度 |
| §2 验前事推断 | 从候选中优选 4-8 年，按 §6.1 结构展开 |
| §3 整体形态 | 覆盖年份的主线形态提炼（结构性曲线 / 拐点），1-2 段话，**非逐年累加** |
| §4 校验对话 | 命主标注用的表格（命中 / 部分命中 / 未命中 / 反向）|
| §5 测试用例价值 | 大运覆盖、结构触发密度、校验价值 |
| 结尾免责声明 | 按本仓库免责模板 |

### 6.3 校验对话固定附录

末尾固定附：

> 请逐条标注：**命中 / 部分命中 / 未命中 / 反向**。命中率作为后续动态推演（大运 / 流年）可信度的基准。

## 七、维护与迭代

### 7.1 修订动机

只有以下三种动机才修订本文档：

1. **新增判定门槛**：从更多命主验前事跑测中识别出新的高能量结构
2. **某条门槛被实证修正**：原本列为门槛的实际不是结构性高能量
3. **格式约定调整**：产出文件结构演进时同步更新

### 7.2 不修订的情况

- 命主特定的发现 → 写入命主级文档，不上升到本方法论
- 单次跑测命中度低 → 调整该次跑测的具体推断措辞，不改方法论
- 流派偏好变化 → 重大决定，应整体讨论
